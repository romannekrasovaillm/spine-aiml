# Architecture Spine — платформа инференса «Синтетика»

> Учебная заглушка кейса 007: три worktree-компонента (gateway, router,
> registry) несут ПОЛНЫЕ копии спайна — почва для дублей и дрейфа.
> Синтетика, не промышленный дизайн.

## AD-1: Единый протокол инференса

**Binds:** gateway, router, registry обмениваются только gRPC; схемы —
в `api/` (protobuf), версионируются вместе со спайном.

**Prevents:** рассинхрон контрактов между компонентами флота.

**Rule:** схемы и инварианты меняются только дельтой `changes/<id>`
(ADDED/MODIFIED/REMOVED → ревью → применение → архив).

## AD-2: Реестр моделей — единственный источник маршрутизации

**Binds:** router опрашивает registry; статические маршруты в конфигах
запрещены.

**Prevents:** расхождение маршрутов при деплое новых ревизий моделей.

**Rule:** fitness-правило `router-no-static-routes` в CONSTRAINTS.yaml.
