погрешности одного прогона): handoff-пакет не добавил заметного времени,
при этом устранил дрейф по двум орг-инвариантам. Это главный
экономический факт кейса.

## Оценка токенов

Недоступна честно (usage API не журналировался до 2026-09-04; в
evidence — сводные логи ~3 КБ). Для оценки «цена пакета в токенах»
(объём пакета в контексте исполнителя) нужен повторный прогон с новой
сборкой — `arch-be metrics --cost-report` даст сравнение рук по
реальному usage.

## Метод для будущих прогонов

контексте, стоимость по тарифу модели — прямое измерение «цены спайна».
