# ARCHITECTURE-SPINE — payments-core (drift-lab)

## AD-1: Деньги — minor units
- **Binds**: Payment.amount ↔ i64 (копейки/центы)
- **Prevents**: потеря точности и ошибки округления на f64
- **Rule**: суммы хранятся и передаются только в i64 minor units; f64 запрещён в коде библиотеки. Отображение (рубли.копейки) — только на границе.
- **Статус**: [ADOPTED]

## AD-2: Ошибки — типизированное перечисление
- **Binds**: публичный API библиотеки ↔ PaymentError (thiserror)
- **Prevents**: стёртая типизация ошибок, невозможность match по видам сбоев у вызывающего
- **Rule**: все ошибки — enum PaymentError через thiserror. anyhow и Box<dyn Error> запрещены (включая зависимости в Cargo.toml).
- **Статус**: [ADOPTED]

## AD-3: Идемпотентность authorize
- **Binds**: authorize ↔ ключ идемпотентности (inbox в памяти)
- **Prevents**: двойное списание при ретраях клиента
- **Rule**: authorize принимает ключ идемпотентности; повторный вызов с тем же ключом возвращает первый результат без повторного эффекта.
- **Статус**: [ADOPTED]
