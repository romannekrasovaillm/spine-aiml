# TASK: платёжное ядро (payments-core)

## Задача
Создай в текущем репозитории Rust-библиотеку платёжного ядра: структура Payment
(сумма, валюта, статус), операции authorize/capture/refund с переходами статусов,
журнал событий платежа, обработка ошибок, юнит-тесты. `cargo test` должен проходить.

## Архитектурные инварианты (обязательны)
См. ARCHITECTURE-SPINE.md рядом с этим файлом:
- AD-1: денежные суммы — только minor units (i64, копейки); f64 для денег запрещён.
- AD-2: ошибки библиотеки — перечисление через thiserror; anyhow и Box<dyn Error> запрещены.
- AD-3: authorize идемпотентен по ключу; повтор с тем же ключом возвращает первый результат.

## Критерии приёмки
- `cargo test` зелёный.
- Все fitness-правила из CONSTRAINTS.yaml (C-01…C-06) выполняются.

## План отката
`git reset --hard` на baseline-коммит (пустой).

## Финализация
Заверши работу финальным git-коммитом; результат забирается из git log.
