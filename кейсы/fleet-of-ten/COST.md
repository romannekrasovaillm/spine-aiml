`evidence/runs.md`.

| Показатель | Значение |
|---|---|
| Исполнители | 10 × Claude Code headless (бэкенд deepseek-v4-pro[1m]), параллельно (tmux) |

| Суммарное машинное время | ~19,8 мин (10 × ~119 с среднее) |

| Токены | **не фиксировались** на момент прогона |

## Оценка токенов

Недоступна честно (тот же статус данных, что в кейсе 004): usage API не
журналировался до 2026-09-04. Пропорция для планирования: десять
параллельных эпиков стоят по стене как один (~3,2 мин против ~2 мин
одиночного) — параллелизм флота почти бесплатен по времени, линейен по
токенам.

## Метод для будущих прогонов

`arch-be metrics --cost-report` (usage исполнителей + тарифы) + стена из
runs.md; повторный прогон с новой сборкой даст сопоставимый COST.
