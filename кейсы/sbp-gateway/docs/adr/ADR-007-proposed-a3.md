# ADR-007. Стратегия реализации: гибрид «ядро собственная разработка + вендорский транспортный адаптер» (Accepted, A3)

- Date: 2026-08-15
- Status: Accepted (решение A3 от 2026-08-15)
- Owner: solution-architect (платёжный контур) + бизнес/CIO
- Related: ADR-001, ADR-003, AD-008

## Context

Маршрут Critical (значимость 11/15): новый компонент, интеграция с внешним оператором, финансовое влияние, КИИ. Ключевая развилка стратегии реализации определяет состав работ, стоимость и сроки. Возможности рынка: сертифицированные вендорские СБП-модули (транспорт к ОПКЦ, СКЗИ, тестовые контуры), банковские процессинговые платформы; с другой стороны — ядро шлюза (API ТСП, статусная машина, сверка, отчётность) тесно связано с АБС и внутренними стандартами банка.

## A3 Decision (машинно-читаемый пакет)

- **choice**: `hybrid` — ядро шлюза (API ТСП, статусная машина, оркестрация, сверка, АБС-интеграция, отчётность) — собственная разработка банка; транспортный адаптер ОПКЦ СБП (протокол НСПК, mTLS/ГОСТ, СКЗИ/HSM, тестовый контур) — сертифицированный вендорский модуль.
- **rationale**: сертифицированный транспорт снижает регуляторный риск и ускоряет прохождение тестовых испытаний НСПК; финансовая логика и АБС-интеграция — конкурентная зона банка и остаются под контролем; граница контракта делает адаптер заменяемым.
- **constraints**: (1) ядро контрактно-независимо от транспорта — единственная зависимость внутренний контракт адаптера (AD-008); (2) вендор обязан предоставить сертификаты ФСТЭК/соответствие требованиям НСПК, тестовый контур, SLA, референсы; (3) реализация транспорта начинается только после подписания контракта с вендором и получения документации НСПК; (4) ключевой материал — в сертифицированном СКЗИ/HSM (ADR-003, ADR-006).
- **rejected options**: `full-vendor` (vendor lock-in, ограниченный контроль над финансовой логикой, сложная кастомизация под АБС, дорогой аудит для ЦБ); `full-inhouse` (редкие компетенции по криптографии/СКЗИ, длинные сроки, высокий риск не пройти испытания НСПК с первого раза).
- **expiry**: пересмотр при (а) отсутствии на рынке вендора, удовлетворяющего constraints (1)–(4); (б) изменении требований НСПК, делающих транспорт неотделимым от ядра. Плановая ревизия — через 12 месяцев боевой эксплуатации.

## Decision

1. **Ядро шлюза — собственная разработка**: API для ТСП, статусная машина платежа (ADR-002), оркестрация, сверка (ADR-004), отчётность, интеграция с АБС (ADR-005).
2. **Транспортный адаптер ОПКЦ — вендорский/сертифицированный**: протокол НСПК, mTLS/ГОСТ, СКЗИ/HSM, тестовый контур НСПК (ADR-003).
3. **Граница контракта** между ядром и адаптером — внутренний REST/очередной контракт шлюза; адаптер заменяем (ADR-003, Reversibility).
4. Выбор конкретного вендора — отдельная процедура (RFP) по критериям constraints.

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| Гибрид (выбран) | Контроль над финансовой логикой; сертифицированный транспорт; замена адаптера без смены ядра | Две команды/два поставщика; внешняя зависимость по срокам транспорта |
| Полностью вендорское решение | Быстрый старт, вендор отвечает за протокол | Vendor lock-in, дорогая кастомизация под АБС, ограниченный контроль, сложнее аудит ЦБ |
| Полностью собственная разработка | Полный контроль, нет вендорских зависимостей | Редкие компетенции (криптография, СКЗИ, протокол НСПК), длинные сроки, риск испытаний НСПК |

## Consequences

### Positive

- Сертифицированный транспорт снижает регуляторный риск и ускоряет подключение.
- Финансовая логика и АБС-интеграция остаются у банка.
- Адаптер заменяем — нет жёсткого lock-in на транспорт.

### Negative

- Две команды/два поставщика — интеграционное и контрактное взаимодействие.
- Вендорский адаптер — внешняя зависимость по срокам и качеству.
- Гибрид сложнее в эксплуатации (разные циклы обновления, мониторинг).

## Reversibility

**reversible** на старте (до боевой эксплуатации) — выбор стратегии можно изменить; после боевой эксплуатации смена транспорта — costly, но возможна (граница контракта это позволяет).
