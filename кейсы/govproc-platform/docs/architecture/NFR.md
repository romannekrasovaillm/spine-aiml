# NFR — Платформа B2G-закупок (v0.1, до первого арендатора)

Цели измеримы, проверяемы на гейтах A4/A5. Профиль нагрузки — гипотеза до обследования заказчика `[ТРЕБУЕТ ПРОВЕРКИ: число заказчиков/поставщиков, объём закупок/год]`.

## Производительность
| ID | Метрика | Цель | Проверка |
|----|---------|------|----------|
| NFR-P1 | Латентность чтения (каталог, извещение), p95 | ≤ 800 мс при 200 RPS | Нагрузочный тест, стенд |
| NFR-P2 | Подача заявки (запись + УКЭП), p95 | ≤ 3 с при пике 50 подач/мин за час до дедлайна | Нагрузочный тест с профилем «дедлайн» |
| NFR-P3 | Трансляция документа в ЕИС (из outbox до отправки) | ≤ 5 мин в штатном режиме | Тест адаптера с эмулятором ЕИС |

## Доступность и DR
| ID | Метрика | Цель | Проверка |
|----|---------|------|----------|
| NFR-A1 | Доступность платформы | 99.5% (рабочие дни 08:00–20:00 МСК) | Мониторинг, отчёт за квартал |
| NFR-A2 | RTO | ≤ 4 ч | Учения DR не реже раза в полгода |
| NFR-A3 | RPO | ≤ 15 мин | Проверка PITR-бэкапов ежемесячно |
| NFR-A4 | Недоступность ЕИС | Не влияет на приём заявок и работу заказчиков | Хаос-тест: отключение эмулятора ЕИС |

## Безопасность и соответствие
| ID | Требование | Проверка |
|----|-----------|----------|
| NFR-S1 | УКЭП на всех юридически значимых действиях; валидация подписи на границе | Контрольный сценарий контура + аудит hash-chain |
| NFR-S2 | Аудит append-only, hash-chain без разрывов | Автопроверка целостности цепочки (ежесуточно) |
| NFR-S3 | ПДн: шифрование at-rest, маскирование в логах, аудит чтения | Скан логов на ПДн (fitness), тест доступа по ролям |
| NFR-S4 | Аттестация ИСПДн (класс — по модели угроз) | Гейт A1: модель угроз; до ввода в эксплуатацию: аттестат |
| NFR-S5 | TLS к гос-системам с сертификатом Минцифры (дедлайн 04.07.2026) | Контрольная проверка соединения с ЕИС |
