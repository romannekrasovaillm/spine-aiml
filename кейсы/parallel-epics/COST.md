# COST — кейс 004 (parallel-epics)

Смета прогона задним числом (2026-09-04, пакет C-4 плана доработок).
Метод и ограничения — внизу; цифры времени — из `evidence/runs.md`.

## Известные факты стоимости

| Показатель | Значение |
|---|---|
| Исполнители | 3 × Claude Code headless (бэкенд deepseek-v4-pro[1m]) |
| Задача | 3 эпика библиотеки spinecalc в изолированных worktree |
| Итог | 15/15 тестов, интеграция с первой сборки |
| Инциденты стоимости | MCP-чтение прервано тишиной 600 с (медленный прокси) — урок: idle-таймауты в таймаутах handoff (1800/3600/7200 с) |
| Токены | **не фиксировались** на момент прогона |

## Оценка токенов

Недоступна честно: полные журналы сессий исполнителей не сохранены в
evidence (есть сводные логи ~2–4 КБ), а usage API тогда не
журналировался (механизм заведён 2026-09-04, пакет C-1). Любая цифра
здесь была бы выдумкой — фиксируем отсутствие данных.

## Метод для будущих прогонов

`arch-be metrics --cost-report` после прогона (usage в журналах
исполнителей, тариф `price_*_per_1m` при задании) + стена из runs.md.
Повторный прогон кейса с новой сборкой даст сопоставимый COST автоматически.
