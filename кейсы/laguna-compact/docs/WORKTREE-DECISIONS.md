# WORKTREE-DECISIONS.md — решения по веткам worktree репозитория

- Date: 2026-09-16
- Контекст: в `spine-aiml` висят ветки worktree, не относящиеся к кейсу `laguna-compact`.
  Решения принимает владелец; этот файл фиксирует, что решено и почему, чтобы ветки
  не «потерялись» и не были выброшены по незнанию.

| Worktree / ветка | Что внутри (факт) | Решение (16.09.2026) |
|---|---|---|

**Правило для чужих веток:** ни одна не удаляется без решения владельца — выброс worktree
(`worktree drop`) уничтожает незакоммиченную работу, а это риск того же класса, что R2
(правки под живым контуром): потеря чужого труда без возможности восстановления.
