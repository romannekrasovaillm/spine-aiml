# Реальные траектории агентной пробы SFT-финала (internal_only)

- Date: 2026-09-25 · источник: `runs/passrate-agentic-20260925-1000/sft/` (пул B, состояние — бронированная копия SFT-финала)
- Режим: штатный (сэмплирование T=1, top_k=20, запрет повторов 4-грамм), `--no-toolcall-force --no-hint`, 1 попытка на задачу, ≤5 ходов
- **Не публиковать** (ADR-005 `internal_only`, ADR-048 п.6): промпты, ожидаемые значения и генерации раскрывают содержимое RL-набора

## 1. Что прибор сохранил, а что нет

Прибор сохранил **примеры отказов** (`diagnosis.examples`) по классам; класс
`a_no_tool_call` — 25 из 25 в выборке (сэмпл 25 из 190 отказов), остальные классы — 0.
**Примеры успешных траекторий прибор не сохраняет вовсе** (в `answers.jsonl` нет признака
`pass`). Это дыра в приборе: разбирать «что сработало» по артефакту нельзя, только по агрегату
(8–12 % на одношаговых типах).

## 2. Отказы класса «модель не вызвала инструмент» (3 сохранённых примера)

Все три — тип `find_concept`, среда `E2_formula`. Во всех: `required_n = 1`, `found_n = 0`,
хода ровно один (вызова нет), кредит 0.

### Пример 1 — шаблон с плейсхолдерами вместо действия

```
задача:  записать формулу <концепт> в LaTeX и расшифровать обозначения
модель:  «## Шаблон вывода … ${DS}^{1} = \dots$ … ${DS}^{6} = \dots$
          ## Примеры … 1. $\frac{DS}{{DS}^{1}}$ и $\frac{1}{n}\sum DS_i$ …»
требуется: 1 значение из инструмента; найдено: 0
```

Наблюдение: модель воспроизводит **форму ответа** (заголовки, LaTeX-каркас), но вместо значения
ставит `\dots`. Похоже на выученный шаблон «как выглядит ответ», без шага добычи данных.

### Пример 2 — ответ есть, значения нет; уход в прозу

```
задача:  то же, другой концепт
модель:  «## Определения … **Oracle-Optimal** — это фундаментальная теорема … $||P_1-P_2||_2 \le \epsilon$ …»
требуется: 1; найдено: 0
```

Наблюдение: модель конструирует правдоподобное определение из соседних терминов, не обращаясь
к каталогу. Формально «ответ по теме», но проверяемого значения нет.

### Пример 3 — рассуждение ушло в английский

```
задача:  то же, третий концепт
модель:  «## Step 1: Understanding the concept — The grpo definition mentions that it's an
          algorithmic primitive used in reinforcement learning …»
требуется: 1; найдено: 0
```

Наблюдение: на «формульных» задачах рассуждение переключается на английский. Это тот же класс,
что был найден ранее по языку генерации: сдвиг языка живёт в начале хода, и здесь он совпадает
с отсутствием вызова — интерфейс инструмента не задействован.

## 3. Что делать по существу (гипотезы, не решения)

1. **Проверить, не является ли «нет вызова» следствием формата.** В наборе вызов инструмента
   размечается тегом; если модель стабильно выдаёт шаблон ответа, вероятный рычаг — доля и порядок
   примеров с вызовом в SFT, а не новые задачи в пуле.
2. **Разделить два дефекта в метрике:** «нет вызова» (55 % траекторий) и «вызов с ошибкой»
   (30–64 % вызовов) — сейчас они сливаются в одном нуле, а чинятся разным.
3. **Добавить в прибор сохранение успешных траекторий** (хотя бы 3 на тип) — иначе «где хорошо»
   описывается только агрегатом, а не примером; сейчас это невозможно.
