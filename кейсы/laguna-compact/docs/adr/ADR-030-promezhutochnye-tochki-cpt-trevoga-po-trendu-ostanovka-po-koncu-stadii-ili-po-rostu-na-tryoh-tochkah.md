# ADR-030. Промежуточные точки CPT: что считать тревогой и когда останавливать

- Date: 2026-09-16
- Status: Proposed
- Инициатор: первый замер полного CPT (шаг 500: K1 ×2.449, K2 ×2.590) и вопрос дельты S3u к архитектору

## Context

**Противоречие в правилах.** ADR-022 п.3б ставит потолок 2× базы «к концу стадии». ADR-029 п.4 объявляет критерием конъюнкцию K1 ∧ K2 на промежуточных точках **и** в конце. Правила для промежуточной точки, превысившей потолок, нет — а первый же замер полного CPT (`v12r`, LR×0.35, шаг 500) дал **K1 ×2.449, K2 ×2.590**, то есть выше обоих потолков.

**Почему это не приговор, а известная форма.** Ступенька в интервале (0, 500] установлена как свойство **высокого LR**, а не протокола и не домена:

- рука **C1** (100 % общий текст, **без домена**, LR×0.35): ×1.85 / ×2.03 на шаге 500 → **×1.245 / ×1.399 к шагу 2000** (S3v);
- рука **C2** (тот же микс `v12r`, **LR×0.035**): ступеньки нет вовсе — ×1.014 / ×1.044 на 500, ×1.005 / ×1.053 к 2000 (S3v);
- калибровочные руки с LR×0.35: ступенька есть у всех, к 2000 приходят в потолок (25-0.35: K1 ×1.520, K2 ×1.745).

**Почему нельзя остановиться по точке.** Если останавливать стадию по любому превышению потолка в промежуточной точке, то **любая** рука с LR×0.35 будет остановлена **всегда** — на норме, которую мы уже измерили и объяснили. Тогда ADR-015 (раннее предупреждение о деградации) превращается в стоп-кран, срабатывающий на штатном поведении, а не на деградации.

## Decision

1. **Потолок 2× — критерий конца стадии** (редакция ADR-022 п.3б сохраняется): вердикт о прохождении CPT даётся по **финальному** чекпойнту полного прогона, по обеим компонентам, конъюнкцией (ADR-027).
2. **Промежуточные точки — раннее предупреждение (ADR-015), а не критерий остановки.** По ним отслеживается **тренд**, а не абсолютное значение.
3. **Тревога** (фиксируется, но стадия не останавливается): точка выше потолка **и** следующая точка не лучше предыдущей (тренд не вниз).
4. **Остановка по промежуточным точкам** — только при **росте на трёх последовательных точках** (каждая хуже предыдущей, все выше потолка). Это форма настоящей деградации, а не ступеньки (исторический пример необратимой деградации — mode collapse на шаге ~169).
5. **Контроль первой четверти.** К концу первых 25 % шагов стадии (для 9776 шагов — к шагу ~2444) конъюнкция обязана быть **в потолке**. Не откатилась за четверть бюджета — это не ступенька, и стадия останавливается по протоколу ADR-016.
6. **Отдельный числовой порог для точки 500 не вводится.** Он противоречил бы измеренной форме: у C2 ступеньки нет вовсе, у LR×0.35 она есть и откатывается; любой единый порог либо даст 100 % ложных срабатываний, либо пропустит реальную деградацию.
7. **Правило тренда распространяется на доменную компоненту — с обратным знаком цели** (дополнено 16.09.2026 по вопросу S3x). Для языка цель — **не превысить потолок** (× базы ≤ 2), поэтому тревога = точка выше потолка и следующая не лучше. Для домена цель — **опуститься ниже базы** (× базы < 1 = выучен, ADR-031 п.4), поэтому:
   - **тревога домена:** точка выше базы (× > 1) **и** следующая не лучше предыдущей (домен не учится);
   - **остановка домена:** три последовательные точки с ростом × выше базы, либо домен не вошёл в «выучен» к концу **первой половины** бюджета (для 9776 шагов — к шагу ~4888). Вторая половина бюджета — время набирать домен, а не входить в него.
   Порог «выучен» остаётся единым (× < 1); отдельной «полосы допуска» для тренда не вводится — иначе правило снова начнёт зависеть от произвольного числа.

## Alternatives Considered

| Вариант | Почему отвергнут |
|---|---|
| **B. Останавливать по любой точке выше потолка** | Даёт ложные срабатывания на **каждой** руке с LR×0.35 (форма ступеньки), то есть стоп-кран на норме. Основание остановки должно отличать норму от деградации, иначе оно бесполезно. |
| **C. Смотреть только финальный чекпойнт** | Обесценивает ADR-015: раннее предупреждение существует именно для того, чтобы не узнать о коллапсе через 7 часов. Исторический коллапс (шаг 169) при таком правиле был бы замечен только в конце прогона. |
| **D. Ввести порог для точек (например, «3× — стоп»)** | Число произвольно: ступенька LR×0.35 доходит до ×2.6 (у полного CPT ×2.449/×2.590), поэтому порог 3× пропустил бы реальную деградацию того же масштаба, а порог 2× — остановил бы норму. |
| **Статус-кво: «пусть решает архитектор по каждой точке»** | Ручное решение на каждой из ~20 точек — это 20 поводов ошибиться одинаково; правило должно быть сформулировано до прогона, а не выводиться заново каждый раз. |

## Consequences

### Positive

- Правило согласовано с **измеренной** формой кривой: остановка происходит на деградации, а не на штатной ступеньке.
- ADR-015 сохраняет смысл: тревога фиксируется и видна, но не останавливает нормальный прогон.
- Появляется механически проверяемое условие контрольной точки (первая четверть бюджета) — его можно вынести в сторож прогона.

### Negative

- **Решение по деградации откладывается** минимум на две-три точки (500–1500 шагов, до ~1 ч прогона): тренд нельзя оценить по одной точке.
- Правило **зависит от знания формы** (ступенька как свойство высокого LR). Для нового протокола, микса или модели форму придётся переизмерять — иначе «ступенька» и «деградация» неразличимы.
- «Тревога без остановки» остаётся **человеческим** решением: механического сторожа пока нет, а значит тревогу можно не заметить в журнале (до реализации сторожа это риск).
- Контроль первой четверти опирается на бюджет стадии (9776 шагов); при смене бюджета шаг проверки пересчитывается.

## Reversibility

Обратимо: правило — надстройка над критерием конца стадии, оно не меняет ни потолок, ни наборы, ни протокол. Ужесточение (например, остановка по двум точкам роста) или ослабление (только финал) — правка одного пункта. Уже принятые решения (ADR-029 о продолжении) правилом не затрагиваются. Стоимость откатa — низкая.
