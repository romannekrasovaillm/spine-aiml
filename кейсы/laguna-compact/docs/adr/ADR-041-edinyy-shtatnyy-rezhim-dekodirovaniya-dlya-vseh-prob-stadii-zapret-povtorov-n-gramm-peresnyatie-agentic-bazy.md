# ADR-041. Единый штатный режим декодирования для всех проб стадии

- Date: 2026-09-18
- Status: Proposed
- Инициатор: результат S3al (штатный режим закреплён в приборе проб) и решение владельца распространить его на агентную пробу

## Context

**Что установлено (ADR-040 п.6, S3ak/S3al).** Вырождение SFT-генераций — это **повторяемость n-грамм**, и она механически снимается запретом повторов 4-грамм: `looped_share` **0.5417 → 0.0000**. Repetition penalty не помогает (0.5833), sampling помогает частично (0.3333). Петли есть **уже с шага 500** и держатся на всём протяжении обучения; **в данных они не живут** (различие внутри корзин длины — ровно 0.0000 на 4 804 парах из 4 808; юниты петель встречаются в наборе **реже** контроля). То есть петля **рождается декодером**, а не воспроизводится из данных.

**Следствие для приборов.** Часть прежних выводов о формате была **измерением петли**, а не модели: незакрытые `<think>` при greedy = 0.5883 артефакта + 0.4118 реального дефекта. Поэтому прибор языковых/форматных проб уже закрепляет штатный режим: запрет повторов 4-грамм — **умолчание**, прогон без него отклоняется с кодом 1, пока не назван `--legacy-decoding` (мост воспроизводимости), а свод проверяет режим **вызовом** прибора, а не чтением описания.

**Проблема несопоставимости.** Агентная проба (`passrate_probe.py`) — часть критерия стадии (ADR-033 п.2в: доля самостоятельных вызовов и pass-rate) — декодирует **своим циклом** (`temperature 1.0`, `top_k 20`) и о запрете повторов не знает. Это значит: **язык и формат измеряются в одном режиме, а агентность — в другом**, и сравнивать их между собой, а также сравнивать агентность «до/после» с уже снятой базой (45.1 %, 158/350) **нельзя**: база получена в legacy-режиме.

**Решение владельца:** распространить штатный режим и на агентную пробу (18.09.2026).

## Decision

1. **Единый штатный режим декодирования для всех проб и замеров стадии:** **запрет повторов 4-грамм** включён по умолчанию во всех инструментах оценки — языковые/форматные пробы, генеративные пробы, **агентная проба** (`passrate_probe.py`) и её производные (agentic-доля, pass-rate).
2. **Legacy-режим сохраняется только для воспроизводимости прошлых чисел** — явным флагом (`--legacy-decoding`), с обязательной пометкой в отчёте «измерено в legacy-режиме, для выводов не годится». Выводы по формату и языку делаются **только** в штатном режиме.
3. **Agentic-база переснимается** в штатном режиме (прежние 45.1 % — 158/350 — сохраняются как исторические, но выходят из критерия). До переснятия базы **вердикт по agentic-доле (ADR-033 п.2в1/в2) не выносится** — сравнение было бы между разными режимами.
4. **Тождество режима проверяется механически:** каждая проба несёт в отчёте `protocol.decoding` (имя режима, параметры), свод отказывается считать метрику, если режим не штатный (или помечает её как legacy). Это тот же приём, что уже работает в приборе языковых проб.
5. **Никаких выводов из смешанных режимов.** Если данные получены до введения правила (в т.ч. числа S3ab/S3ag/S3ai/S3aj/S3ak) — они **остаются как исторические**, с указанием режима; повторное использование допускается только для сравнения с замерами в том же режиме.
6. **GPU-инцидент фиксируется как ограничение:** 18.09 локальная 4080 перестала принимать CUDA (`Xid 31`), из-за чего вердикт по языку при n ≥ 100 **не получен** (пилот: кириллица по чистым 0.6691, покрытие 0.5417). Возврат к замеру — после восстановления устройства (`rmmod/modprobe nvidia_uvm` или перезагрузка, решение владельца). CPU-режим отвергнут числом: 2.8 ток/с → ≈20 ч на одно состояние.

## Alternatives Considered

| Вариант | Почему отвергнут |
|---|---|
| **B. Оставить агентную пробу в своём режиме** | Критерий стадии станет набором несопоставимых чисел: язык/формат в штатном режиме, агентность в другом, база — в третьем (legacy). Решения по таким числам уже дважды приводили к ложным выводам (коллинеарные миксы, «ноль самовызовов» на SFT-чекпойнте с форсированием). |
| **C. Перевести всё на legacy (отказаться от запрета повторов)** | Тогда метрики формата снова измеряют петлю: 59 % величины признака — артефакт. Это уже стоило нам нескольких дельт. |
| **D. Пересчитать agentic-базу аналитически, без нового прогона** | Невозможно: legacy-прогон не сохранял распределение n-грамм траекторий, а петля меняет и число ходов, и исход. Нужен новый прогон в штатном режиме. |
| **Статус-кво: решить после вердикта по языку** | Вердикт по языку заблокирован железом; перенос правила на агентную пробу от железа не зависит, а несопоставимость базы копится с каждым замером. |

## Consequences

### Positive

- Критерий стадии становится **сопоставимым**: язык, формат и агентность измеряются одним протоколом.
- Устраняется класс ложных выводов «метрика выросла/упала», вызванных сменой режима декодирования (после этого правила такое расхождение будет видно по полю `protocol.decoding`).
- Переснятие agentic-базы даёт **корректную точку отсчёта** для SFT→RL (ADR-033 п.2в: «доля не падает, pass-rate растёт»).

### Negative

- **Разрыв с историей:** все прежние числа (agentic 45.1 %, языковые и форматные метрики S3ab…S3ak) становятся историческими; для сравнений нужны повторные замеры, то есть **дополнительные часы GPU** — а GPU сейчас недоступен.
- **Переснятие базы требует ресурса**, которого нет: до восстановления 4080 пункт 3 невыполним, и вердикт по агентности остаётся отложенным (как и вердикт по языку).
- **Запрет повторов n-грамм меняет поведение модели** (не только метрику): он влияет на длину, на вероятность повторов в содержании (например, повторы терминов) — возможны случаи, когда «полезный» повтор подавляется. Риск назван; проверяется на пробах с содержательной проверкой.
- **Правило расширяет область действия** с прибора проб на агентную пробу — то есть затрагивает часть критерия стадии; это архитектурное изменение, а не косметика прибора.

## Reversibility

Обратимо: режим задаётся флагом, legacy-путь сохранён и работает (`--legacy-decoding`), исторические числа не удаляются. Откат = вернуть прежний режим по умолчанию в агентной пробе и признать agentic-числа несопоставимыми (как сейчас). Необратимо только потраченное время на переснятие базы — но оно и так требуется для сопоставимости. Отдельно: **решение не зависит от состояния GPU** — код и правило вводятся сейчас, замеры выполняются после восстановления железа.
