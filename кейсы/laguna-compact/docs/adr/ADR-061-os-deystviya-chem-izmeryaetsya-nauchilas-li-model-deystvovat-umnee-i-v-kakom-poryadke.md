# ADR-061. Ось действия: предмет, метрика и порядок

- Date: 2026-09-25
- Status: **Accepted** (владелец, 25.09.2026: «мне нужен ответ на вопрос, научилась ли модель действовать умнее»)
- Отменяет часть `ADR-060`: вариант развилки выбран — измерение действия (в терминах ADR-060 это направление B), при этом порядок шагов уточнён и RL в нём **не первый**

## Context

Владелец выбрал цель: получить **ответ**, а не запустить конкретную стадию. Вопрос в исходной
формулировке — «научилась ли (дообученная) модель действовать умнее».

Проверка контура 25.09.2026 показала, что этот вопрос **сейчас не измерим**:

| Что нужно для ответа | Состояние в контуре |
|---|---|
| Заземлённые задачи (награда по состоянию среды, ADR-049) | **скелет 5 задач × 3 инструмента** (`data/grounded-skeleton`), контракт среды G1–G4 доказан; **пул стадии не собран** |
| Прибор измерения действия **политики** (rollout модели по средам, кредит по состоянию) | **отсутствует**: `tools/grounded_runner.py` прогоняет контракт среды (положительный контроль, no-action, лимит шагов), но не политику; `tools/passrate_probe.py` измеряет текстовый пул через `search_concepts` |
| База сравнения «до действия» | есть чекпойнты базы, CPT-финала и SFT-финала, но на заземлённых задачах они не замерялись ни разу |
| Полоса трудности `p*` (задачи в 0,25–0,80) | не измерена у заземлённых задач; у текстового пула полоса **пуста** (0 из 9162) |

Отсюда: «запустить RL» — не первый шаг, а последний. Без прибора измерения действия RL нечем
ни обосновать, ни принять: неизвестно, что именно он должен улучшать и по какому числу.

## Decision

1. **Предмет оси действия** — заземлённые задачи: награда по **состоянию среды** (G1–G4, ADR-049 п.1),
   кредит бинарный (AD-11), успех без действия невозможен (проба no-action = 0).
2. **Метрика ответа** — `pass_rate` по состоянию среды на заземлённом наборе, с тремя обязательными
   спутниками: доля `no-action` траекторий, доля ошибок инструмента, среднее число действий.
   Ответ считается по **разности** между состояниями, с порогом различимости, объявленным до замера
   (SE разности по n задач; при 1 попытке на задачу pass@k не заявляется).
3. **Базы сравнения — три состояния, снятые одним прибором и одним протоколом**: базовая модель,
   CPT-финал (вход SFT), SFT-финал. Это отвечает на вопрос в статике: **научилась ли модель
   действовать** (по стадиям), без RL.
4. **Порядок шагов (каждый следующий — только если предыдущий дал предмет):**

   | # | Шаг | Что отвечает | Цена (источник) |
   |---|---|---|---|
   | 1 | **Прибор измерения действия** (rollout политики по заземлённым задачам, кредит по состоянию, поверх контракта `grounded_runner`) | создаёт измеримость — без него вопроса нет | разработка (оценка: часы–дни) |
   | 2 | Замер «до» на **скелете 5 задач**: база / CPT / SFT | «действует ли SFT лучше входа» — **сигнал**, не вердикт (n = 5) | часы (вес 0.5B, локальная 4080) |
   | 3 | Сборка заземлённого **пула стадии** (≥ 50 задач) + проба G2 на нём + перевыпуск доказательства | статистика и полоса `p*` | ≈1–2 дня CPU (оценка ADR-049; в `RL-BRANCH-COST.md`) |
   | 4 | Замер «до» на пуле: база / CPT / SFT | вердикт «научилась ли действовать» | часы |
   | 5 | **RL-стадия** (только если шаг 4 дал ненулевую базу и полосу) | «улучшает ли RL действие дальше» | 18–30 ч стенда (оценка, ADR-049 п.10) |
   | 6 | Замер «после» тем же прибором и протоколом | ответ по оси действия | часы |

5. **Шаг 5 не запускается без шага 4.** Если у SFT-финала на заземлённом пуле `pass_rate ≈ 0`
   и полоса пуста, RL повторит историю текстового пула (вырожденная награда, ADR-017) — сначала
   чинится предмет (задачи/прибор/полоса), а не запускается обучение.
6. **Ось S4 (`judge_mean(RL) > judge_mean(SFT)` на OOD-парах) не отменяется и не смешивается**
   с осью действия: это разные предметы, и их числа не сравниваются между собой.
7. **Правила, которые шаги обязаны соблюдать:** бронь предмета (ADR-058), одна нагрузка на стенд
   (AD-5), идентичность входа (ADR-051), кредит бинарный (AD-11), `result-report.json` — только
   по факту.

## Alternatives Considered

| Вариант | Почему отвергнут |
|---|---|
| **Запустить RL сразу (шаг 5 первым)** | Нечем принять результат: прибор измерения действия отсутствует, база «до» не снята, полоса `p*` не измерена. Прогон закончился бы либо вырожденной наградой, либо числом без точки сравнения |
| **Ответить по текстовому пулу (`passrate_probe`)** | Это другая ось: там кредит по совпадению слагов, а не по состоянию среды; на текстовом пуле (в2) рост решаемости не показан (0,0457 против 0,0543) — вопрос о действии он не адресует |
| **Считать действием долю `tool_call`** | Уже измерено и уже известно: 0,3514 → 0,4543. Доля вызовов отвечает «зовёт ли», а не «получается ли»: 30–64 % вызовов оканчиваются ошибкой инструмента |
| **Оставить вопрос без ответа (ADR-060 п. C)** | Отвергнут владельцем: ответ нужен, и он достижим — через прибор и замер «до», без обязательного RL |

## Consequences

### Positive

- Вопрос разложен на измеримые шаги; первые два дешёвые и дают ответ уже без RL.
- Появляется прибор, которого не было: измерение действия политики по среде — он нужен и для RL,
  и для приёмки, и для сравнения стадий.
- Риск «сжечь 18–30 ч стенда впустую» снят условием п. 5 (шаг 5 не стартует без шага 4).

### Negative

- Ответ откладывается: без прибора и пула его не будет; «сегодня» он недостижим.
- Появляется новая работа (прибор + сборка пула), которой не было в исходном бюджете ревизии.
- Смена предмета замера необратима в том смысле, что числа текстового пула и заземлённого пула
  несравнимы: смешивать их в одном вердикте нельзя.

## Reversibility

Обратимо на каждом шаге: прибор и пул — новые артефакты, их можно не принимать; замеры «до» никого
не обязывают запускать RL. Точка необратимости — запуск шага 5 (RL-стадия), как и было объявлено в
ADR-060.
