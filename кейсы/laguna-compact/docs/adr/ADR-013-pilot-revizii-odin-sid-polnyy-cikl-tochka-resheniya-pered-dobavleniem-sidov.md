# ADR-013. Пилот ревизии

- Date: 2026-09-14
- Status: Proposed
- Решает: выбор бюджета протокола (ADR-008 п.4 → ADR-011 п.5). Выбор владельца — **вариант D**

## Context

Бюджет измерен полностью (ADR-008, ADR-011): на сид — CPT 7.0 ч + SFT 20.3 ч/эпоху
+ RL 12.3 … 17.3 ч + eval ≈ 2 ч. Три сида с тремя эпохами SFT — ≈ 10.4 суток
монополии стенда; один сид — ≈ 3.5 суток. Разница между «узнать рано» и «узнать
поздно» — почти неделя занятого GB10 и остановленного автономного контура лесенки.

Ось AD-1 сравнивает RL с SFT-базой **на одном и том же чекпойнте**, поэтому
направление эффекта видно уже на одном сиде; статистика (≥ 1 std) — нет.

## Decision

1. **Фаза 1 — пилот, один сид (42), полный цикл:** CPT (9776 шагов ≈ 7 ч) → SFT
   3 эпохи (≈ 61 ч) → RL 500 шагов (12.3 … 17.3 ч) → eval (192 задачи +
   `eval_sft` baseline на том же SFT-чекпойнте). Итого ≈ **3.5 суток** + eval.
2. **SFT-данные пилота — замороженный `sft_train_v12`.** Замкнутый цикл синтеза
   (ADR-006, `closed-loop-tool-traj-synthesis`) выносится в отдельную дельту
   **после** подтверждения направления: его реализация (генерация + верификация +
   отбор) не влезает в бюджет пилота, а подмена данных внутри пилота убила бы
   сопоставимость с ним же.
3. **Точка решения — сразу после пилота, по четырём критериям:**
   (а) направление оси: `judge_mean(RL) > judge_mean(SFT)` на этом сиде
   (без требования std — статистики нет);
   (б) отсутствие дегенерации: энтропия политики не ниже 1.0 (стоп-порог 0.5),
   `clip_frac < 0.2`, доля timeout-деградаций не растёт монотонно;
   (в) общий язык: `ppl_general` без роста > 15 % без компенсации в `ppl_domain`
   (эвристика контура; при попадании в серую зону решение принимает владелец);
   (г) полнота доказательств: манифесты, `eval_results.json` и `eval_results_sft.json`,
   отсутствие необъяснённых инцидентов.
4. **Развилка после точки:**
   - **направление есть** → фаза 2: **пул v2 (среды E1–E7 + env_types), сначала один сид**
     (≈3.5–4 суток + прибор ≈4 ч), затем решение о двух оставшихся. *Уточнение владельца
     16.09.2026:* фаза 2 идёт на **расширенном пуле** (ADR-021), поэтому пилот **не является
     её первым сидом** — статистика фазы 2 собирается внутри себя, а результат пилота
     фиксируется отдельной серией. Выбор пула сознательно меняет сопоставимость с пилотом
     ради разнообразия среды (7 типов задач против 3); это записано как принятая цена;
   - **направления нет** → стоп. Формулировка результата: «на одном сиде эффект
     RL над SFT не обнаружен», артефакты сохраняются, решение о дальнейшем
     (менять SFT-режим, менять пул, менять ось) — за владельцем, новым ADR.
5. **Порядок запуска:** детерминизм-проба (S3a) обязана завершиться **до** старта
   пилота (AD-5: одна нагрузка за раз). Её вывод определяет, включать ли
   детерминированный режим в пилот; если расхождение остаётся и цена высока —
   фиксируется как ограничение, а не как повод не запускать пилот.
6. **RL-пул пилота** — отфильтрованный `rl_tasks_revpool_v1.jsonl` (27 992 задачи,
   ADR-007), положенный на `gb10-shared` (AD-4).

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **A. Пилот одним сидом, затем решение** (принято) | Риск необратимой траты срезан втрое; направление видно за 3.5 суток; полный протокол остаётся доступным | Вывод после фазы 1 неполон (нет std); при положительном решении календарь тот же, что у полного протокола |
| **B. Сразу 3 сида × 3 эпохи ≈ 10.4 сут** | Никаких промежуточных решений, статистика сразу | Неделя монополии до первого знания; при провале — потеря 10 суток, а не 3.5 |
| **C. 3 сида × 1 эпоха ≈ 5.3 сут** | Статистика есть, вдвое дешевле | Режим SFT иной, чем во всех исторических прогонах — сравнение с v12 теряется |
| **D. Один сид без второй фазы ≈ 3.5 сут** | Самый быстрый результат | Разброс по сидам не измеряется: критерий AD-1 придётся переписывать, и это необратимо для выводов |

## Consequences

### Positive

- Решение о неделе стенда принимается **после** получения направления, а не до.
- Пилот остаётся полным циклом (все стадии), поэтому проверяет контур целиком —
  его результат не выбрасывается, а становится первым сидом фазы 2.
- Замкнутый цикл SFT вынесен явно: иначе он скрыто удлинил бы пилот и сломал
  сопоставимость внутри него самого.

### Negative

- **Направление на одном сиде может быть ложным** (шум eval: при 192 задачах SE ≈ 3.6 %):
  положительное решение по фазе 1 способно привести к фазе 2, где эффект не подтвердится.
  Это принимается как цена раннего решения.
- **Два решения вместо одного**: точка решения требует участия владельца через
  ≈ 3.5 суток — то есть человек в цикле дважды, а не единожды.
- **Зеркальный риск:** если пилот покажет «направления нет» из-за одного неудачного
  сида, фаза 2 не состоится, и вывод останется неполным. Именно поэтому критерий (а)
  сформулирован как «направление», а не «значимость».
- **Пилот не даёт std**, поэтому сравнение с историческими прогонами v12 остаётся
  качественным (по режиму: 3 эпохи, тот же микс, тот же чекпойнт-протокол).

## Reversibility

**reversible.** Фаза 2 — отдельное решение; остановка после пилота не отменяет его
результатов (они становятся первым сидом, если решение продолжить). Данные и веса
не мигрируют. Необратимо только потраченное стендом время (≈ 3.5 суток) и задержка
возврата ресурса лесенке (ADR-012: ≤ суток после снятия результата).
