# ADR-031. Пик LR полного CPT: ×0.035 вместо ×0.35

- Date: 2026-09-16
- Status: Proposed
- Инициатор: S3v (язык) и S3w (домен) — цена LR измерена по обеим метрикам

## Context

**На чём стоял выбор LR×0.35.** ADR-029 п.2 продолжил CPT-стадию на замороженном миксе `v12r` с пиком **LR×0.35** — конфигурация проходила конъюнкцию K1 ∧ K2 (×1.520 / ×1.745). Выбор делался при **отсутствии данных о цене LR по домену**: было известно только, что LR×0.7 проваливает обе компоненты языка, а LR×0.35 их проходит.

**Что дали два замера.**

S3v (язык, тот же микс, тот же сид, различается **только** LR): `25-0.35` — ×1.520 (K1) / ×1.745 (K2); `C2` (**LR×0.035**) — **×1.005 / ×1.053**. Разрыв ×1.51 / ×1.66, а по историческому `v1` — ×4.81.

S3w (домен, тот же микс, тот же сид, снова различается **только** LR), решающий набор `domain_eval_v2.txt` (200 документов, база 11.134115856, sha256 `7ac83fe3…`):

| Пара | домен, ×базы | K1 × | K2 × |
|---|---|---|---|
| `25-0.35` (LR×0.35) | 4.3490 = **×0.391** | ×1.520 | ×1.745 |
| **`C2` (LR×0.035)** | 4.2708 = **×0.384** | **×1.005** | **×1.053** |

- **Домен выучен** в обеих конфигурациях (×0.384 < 1, то есть в ×2.6 от базы).
- **Сопоставимость:** отношение отношений **0.982** — номинально на 1.8 % в пользу низкого LR, то есть **выигрыша по домену у LR×0.35 нет**.
- **Язык:** низкий LR лучше в **×1.51 (K1)** и **×1.66 (K2)**.
- **Чувствительность метрики проверена вакуумной рукой:** `C1` (в обучении домена нет вовсе) теряет домен в ×3.35…×4.47 — значит близкие к базе числа `C2` не слепота прибора.
- Тождество прибора доказано числом: пять исторических эталонов (11.931923888 / 9.290193903 / 11.134115856 / 7.504686374 / 6.159936) воспроизведены в 30 сверках с расхождением 0.0 при пороге ±1e-4.

**Смысл.** Платить языком, не получая ничего по домену, незачем: конфигурация LR×0.35 — строго доминируемая по измеренным метрикам.

## Decision

1. **Пик LR полного CPT — ×0.035** (замена ADR-029 п.2). Остальные параметры без изменений: микс `v12r` (заморожен ADR-003, 9776 шагов по бюджету ADR-008), seed 42, тот же образ и версия пайплайна.
2. **Текущий прогон с LR×0.35 (запущен 19:35) останавливается** по протоколу вмешательства ADR-016: корректная остановка, **сохранение чекпойнтов и логов** как артефакта «цена высокого LR» (он нужен как доказательство доминируемости), фиксация состояния в манифесте. Жёсткое убийство процесса запрещено.
3. **Критерий стадии не меняется:** конъюнкция K1 ∧ K2 на конце (ADR-027), правило промежуточных точек и контроль первой четверти (ADR-030), плюс домен-метрика.
4. **Ратификация домен-метрики** (дополнение к ADR-022 п.3, где потолок задан только для языка): решающий доменный набор — `domain_eval_v2.txt` (200 документов; `domain_eval.txt` из 5 документов остаётся исторической шкалой и не усредняется с ним — ADR-015 называл его слабым прибором по числу документов); правило чтения — **× базы < 1 = домен выучен**, полоса сопоставимости при сравнении конфигураций — **отношение отношений ≤ ×2**.
5. **Названное допущение.** Профиль LR измерен на 2000 шагах калибровки и переносится на бюджет 9776 шагов полного прогона. Это допущение (оно же зафиксировано в «Отрицательных» ADR-029) и остаётся риском: при низком LR выход на плато может быть медленнее.

## Alternatives Considered

| Вариант | Почему отвергнут |
|---|---|
| **B. Продолжить LR×0.35** | Язык проходит (×1.52), то есть формально допустимо, но: тратится 7 ч стенда на конфигурацию с пробитым языком, и выигрыша по домену нет (0.982 против низкого LR). Платить ×1.5 языка за ноль по домену — не решение, а инерция. |
| **C. Промежуточный LR (например ×0.1)** | Не измерен: сетка дала ×0.7 / ×0.35 / ×0.035. Назначать промежуточное значение без замера — тот же класс ошибки (решение по необоснованному числу), который в этой ревизии отзывался уже трижды. |
| **D. Дождаться конца семичасового прогона и решить потом** | Цена: 7 ч стенда ради чекпойнта, заведомо худшего по языку, при неизбежном перезапуске. Артефакт «цена высокого LR» получается и при ранней остановке — чекпойнты сохраняются. |
| **Статус-кво: не трогать идущий прогон** | Сохраняет инерцию и теряет лучшую конфигурацию; при этом данные для решения уже полны — обе метрики измерены на одном миксе и одном сиде. |

## Consequences

### Positive

- Полный CPT идёт в конфигурации, лучшей по **обеим** измеренным метрикам (язык ×1.005 против ×1.52 при сопоставимом домене).
- Ратифицированы домен-метрика и правило её чтения — до этого доменного порога в правилах контура не было вовсе.
- Доминируемость LR×0.35 доказана и сохраняется артефактом, а не забывается.

### Negative

- **Полтора часа прогона уходят в артефакт** (чекпойнты LR×0.35 сохраняются как «цена высокого LR», но как результат стадии не используются).
- **Перенос профиля с 2000 на 9776 шагов остаётся допущением**: поведение низкого LR на длинной дистанции не измерено; возможный риск — более медленный выход на плато по домену (данные C2 его не подтверждают, но и не исключают).
- **Стенд занят перезапуском** — окно монополии ревизии продлевается, автономная лесенка остаётся на паузе дольше.
- Решение меняет конфигурацию стадии **второй раз за сутки** (LR×0.35 → · → ×0.035): журнал требует пометки, а доверие к выбранным числам опирается теперь на два независимых замера, а не на один.

## Reversibility

Обратимо полностью: ADR-029 (LR×0.35) сохраняется как рабочая альтернатива, чекпойнты LR×0.35 остаются на диске, переключение назад возможно остановкой нового прогона. Необратима только потраченная цена — 1.5 ч стенда. Стоимость откатa — низкая, поскольку критерий стадии (конъюнкция + домен) не менялся, а менялась лишь конфигурация, из которой он проверяется.
