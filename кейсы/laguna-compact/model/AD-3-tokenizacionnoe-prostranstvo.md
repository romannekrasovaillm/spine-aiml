- **Binds**: претокенизация ↔ SFT-маскирование ↔ RL-роллауты ↔ eval-харнес
- **Prevents**: повтор класса дефекта 17.08 (`pretokenize.py` без `add_special_tokens` → `<tool_response>` остался сабтокеном → маска `TOOL_RESP_IDS` молча не срабатывала → модель училась генерировать вывод инструмента, проверка: id 151667 = 0 вхождений)
- **Rule**: 8 спецтокенов (`<think>`, `</think>`, `<tool_call>`, `</tool_call>`, `<tool_response>`, `</tool_response>`, `<reasoning>`, `</reasoning>`) — контракт **токен-пространства**: все обязаны маппиться в единый id (дефект 17.08 — рассыпание на сабтокены, из-за которого маска молча не срабатывала). Вхождения в обучающем кэше обязательны для **6 токенов формата v12**; `<reasoning>`/`</reasoning>` в корпусе отсутствуют (0 вхождений во всех 42 кэшах) — это не дефект, и дополнять корпус этими тегами запрещено (ADR-004). Чат-формат един в SFT, RL-харнесе и eval. Страж: C-008.
