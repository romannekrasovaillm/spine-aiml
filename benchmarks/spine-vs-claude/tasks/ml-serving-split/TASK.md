# Задача: разделение train/serve в ML-платформе

## Постановка

Вы — архитектор ML-платформы. Монолитный сервис `ml-monolith` одновременно
готовит признаки, обучает модель и обслуживает онлайн-инференс. Обучение
блокирует инференс (деплой модели требует рестарта сервиса), признаки
считаются дважды (train/serve skew), а масштабирование инференса тянет за
собой GPU-обучение.

Спроектируйте целевую архитектуру: выделение обучающего и сервирующего
контуров с общим слоем признаков. Решение должно быть зафиксировано в
артефактах ниже — их проверит механический гейт, а не рецензент.

## Что нужно сдать

Ровно эти файлы (пути от корня рабочего каталога):

1. `docs/ARCHITECTURE-SPINE.md` — архитектурный спин: инварианты, каждый
   помечен `AD-<n>` (например `### AD-1. Признаки считаются один раз`).
2. `docs/adr/ADR-00N-<slug>.md` — минимум одно решение в формате ADR:
   заголовок `# ADR-NNN. <название>`, статус, контекст, решение,
   последствия, отвергнутые альтернативы.
3. `DECISION.md` — журнал решений (формат ниже).
4. `TRACE.md` — адресный след приёмки (формат ниже).
5. `ACCEPTANCE-EVIDENCE.md` — доказательства по каждому приёмочному
   критерию.

`ACCEPTANCE.md` менять **нельзя**: приёмочные тесты зафиксированы человеком
до начала работы. Любая правка этого файла обнуляет результат.

## Формат `DECISION.md`

```
# Журнал решений

- Approver: <ФИО человека, принявшего решение>
- spec: sha256:<64 hex-символа — хэш файла SPEC.md>

## DEC-001 (2026-09-11)
- Решение: <что решили>
- Обоснование: <почему>
- Отвергнуто: <альтернатива и причина отказа>
- Срок пересмотра: <YYYY-MM-DD>
```

Точный хэш `SPEC.md` получите сами (`sha256sum SPEC.md`); гейт сверит его с
замороженным значением.

## Формат `TRACE.md`

По одной строке на каждый приёмочный критерий из `ACCEPTANCE.md`:

```
AC-01 -> ADR-001
AC-02 -> ADR-001
```

Слева — идентификатор критерия приёмки, справа — идентификатор ADR, который
его обеспечивает. Адресный след обязателен: критерий без адреса считается
непокрытым.

## Формат `ACCEPTANCE-EVIDENCE.md`

```
- AC-01: docs/adr/ADR-001-train-serve-split.md#L14
```

Ссылка вида `<файл>#L<строка>` — та же дисциплина `path:line`, что в
механических проверках харнесса.
