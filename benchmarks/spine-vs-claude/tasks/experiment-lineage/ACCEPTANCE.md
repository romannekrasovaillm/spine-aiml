# Приёмка: граница происхождения экспериментов

Зафиксировано человеком ДО генерации. Не изменять: хэш файла сверяется
гейтом (`acceptance_untouched`).

- **AC-01.** Для продовой модели определён машинно-читаемый идентификатор
  запуска, породившего её артефакт.
- **AC-02.** Цепочка происхождения включает версию датасета и коммит кода
  запуска, а не только метрики.
- **AC-03.** Происхождение проставляется автоматически при обучении; ручной
  ввод — исключение с явной пометкой.
- **AC-04.** Реестр моделей хранит метаданные, достаточные для аудиторского
  ответа без чтения ноутбуков.
- **AC-05.** Публикация в прод отклоняет артефакт незавершённого запуска.
- **AC-06.** Привычный цикл исследователя не требует новых ручных шагов, кроме
  уже существующих.
- **AC-07.** Названы владелец контракта происхождения и лицо, принявшее
  решение (именной аппрувер), в журнале решений.

Проверка адресности: каждая позиция `AC-NN` должна быть адресно привязана в
`TRACE.md` к решению (`AC-NN -> ADR-NNN`) и подтверждена ссылкой
`path:line` в `ACCEPTANCE-EVIDENCE.md`.
