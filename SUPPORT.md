# SUPPORT — поддержка Spine AI/ML Edition

Снимок: 2026-09-22.

## Канал

- Вопросы и дефекты — GitHub Issues репозитория
  (`github.com/romannekrasovaillm/spine-aiml/issues`): дефект — по шаблону
  Bug report, предложение — Feature request.
- Уязвимости — по процедуре `SECURITY.md` (не в публичный трекер).

## Сроки реакции (целевые)

| Severity | Определение | Реакция | Целевое решение |
|---|---|---|---|
| S1 | потеря данных, утечка секретов, исполнение чужого кода | 1 рабочий день | hotfix или workaround в 3 рабочих дня |
| S2 | гейт/инструмент не работает по заявленному контракту | 2 рабочих дня | фикс в следующем релизе |
| S3 | косметика, документация, feature-request | 5 рабочих дней | по ROADMAP |

Проект ведётся в режиме best effort, без обязательств по срокам.

## Политика версий

- SemVer по тегам `v*` (см. `CHANGELOG.md`); схемы CONSTRAINTS/model/
  headless-JSON — только аддитивные изменения (SDK-контракт,
  `sdk/CONTRACT.md`); ломающие — через ADR с миграционной инструкцией.
- Окно поддержки: текущий минорный релиз и предыдущий; фиксы ИБ — на оба,
  функциональные — только на текущий.

## Что приложить к дефекту

Вывод `arch-ml doctor`, версию (`arch-ml --version` или git-тег), команду
запуска, фрагмент журнала сессии (`sessions/*.jsonl` — предварительно
проверить на секреты; redactor покрывает типовые форматы, не все).
