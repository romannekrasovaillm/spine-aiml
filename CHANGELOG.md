# Changelog

## [Unreleased]

### Добавлено

- Плейсхолдер `{repo}` в `args` кодовых харнессов (все режимы prompt_mode и
  ACP-транспорт): подставляется абсолютный путь репозитория прогона — для
  харнессов, которым рабочий каталог нужен явным флагом (hermes `--in
  {repo}`; без него hermes восстанавливает cwd прошлой сессии и пишет
  артефакты мимо репозитория прогона).
- Якорь рабочего каталога в футере контракта каждого прогона («Рабочий
  каталог прогона: `<repo>`…»): исполнители с собственным cwd (терминал
  hermes стартует в ~, агент openclaw — в своём workspace) пишут артефакты
  и `.arch-handoff/result.json` в репозиторий прогона, а не мимо него.

### Изменено

- TUI, читаемость диалога: проза верстается в **меру чтения** — не шире 100
  колонок (`MAX_READING_WIDTH`) независимо от ширины терминала; тело блока
  ответа идёт под желобком `▎`, а перенос сохраняет висячий отступ пункта,
  цитаты и строки кода (перенос переехал в слой вёрстки markdown —
  `src/tui/text.rs::markdown_lines`, где ещё известен маркер строки).
  «Мысли» модели в диалоге сокращены до одной строки со счётчиком скрытого,
  живой хвост инструмента — до одной строки (80 знаков) с подвеской `↳`.
  Раньше на широком терминале строка ответа растягивалась на 130–150
  колонок, а продолжение абзаца начиналось с нулевой колонки и читалось
  как новый абзац.

## [0.3.0] — 2026-09-23

Прозрачность агентных прогонов: протокол ACP для кодовых харнессов,
метрики попадания в KV-кэш, защита TUI от ANSI-мусора, контрактная
дисциплина исполнителей.

### Добавлено

- ACP-транспорт субагентов (ADR-049): `transport = "acp"` в `[harnesses.*]`
  (напр. `binary = "kimi", args = ["acp"]`) — initialize/session new|resume|
  prompt|cancel, политика разрешений `acp_permission` (fail-closed),
  живая проекция tool/plan/usage в лог прогона. Политика контекста:
  свежая сессия по умолчанию, возобновление — по алиасу `acp_session`.
- Метрики KV-кэша: колонка «Кэш hit %» в `arch-ml metrics --cost-report`
  (по модели/сессии/итог), строка «Попадание в prompt-кэш» в `arch-ml
  metrics`, индикатор «· кэш NN%» в статус-баре TUI, поле `cached_tokens`
  в журнале сессий; у субагентов — строка токенов и hit-rate в отчёте
  `reports/subagents/<id>.md`; у ACP-агентов — `_meta.cached_tokens`
  из `usage_update` (контракт в `docs/harness_integrations.md`).
- Номер версии (из Cargo.toml) на стартовом сплэше и под логотипом в чате.

### Исправлено

- TUI: ANSI ESC-последовательности из вывода дочерних процессов
  (харнесс-прогоны, субагенты) больше не попадают в кадры ratatui —
  раньше терминал исполнял их, оставляя «мусор» цветных блоков
  (`ansi::strip` во всех точках показа внешнего текста; отчёт
  фоновой задачи чистится и перед отправкой в контекст модели).
- Субагенты: usage сессии больше не теряется (переведена на стрим-путь
  с внутренним каналом событий).
- Контрактная дисциплина харнесс-прогонов (инцидент 09.2026: 61/189 прогонов
  без JSON-контракта, ещё 8 — вне схемы): канонический футер контракта
  добавляется к задаче каждого прогона (ad-hoc задачи не несут TASK.md);
  второй канал приёмки — файл `.arch-handoff/result.json` (устойчив к обрыву
  стрима; старый файл удаляется перед прогоном); дозапрос-ремонт — нормально
  завершённый прогон без валидного контракта получает один bounded раунд
  (≤ 5 мин) с точной причиной отказа и хвостом вывода (по ACP — в той же
  сессии); источник контракта фиксируется (`ContractOrigin`: stdout /
  result.json / дозапрос) и помечается в сводке.
- Парсер контракта: упоминание «```json» в прозе (цитата инструкции) больше
  не съедает настоящий fenced-блок; перед разбором снимаются
  ANSI-последовательности; шаблон схемы в TASK.md/футере/дозапросе — инлайн,
  чтобы эхо промпта не проходило как контракт.

## [0.2.0] — 2026-09-22

Волна по внешнему ревью репозитория (13 пунктов: идентичность, порог входа,
CI-покрытие, вес репозитория).

### Добавлено

- `README.en.md` — полная английская версия; README.md сокращён до
  быстрого старта и витрины (< 300 строк; обзор возможностей переехал в
  `docs/features.md`).
- `examples/ml-experiment/` — офлайн-демо fitness-гейта (ML-06/ML-09):
  красное состояние → фикс → PASS, без API-ключей и GPU.
- `examples/archify/ml-pipeline-v1.architecture.json` — ML-фикстура контура
  диаграмм (9/9 checks, composition pass).
- `examples/mermaid/ml-pipeline.mmd` — ML-пайплайн для примера
  mermaid → ASCII в README.
- CI: workflow `sdk.yml` — тесты Python SDK (3.10/3.12), Rust SDK, Java SDK
  (JDK 21) и плагина hypothesis-router; запуск по изменениям `sdk/`, `aiml/`.
- CI: identity guard — термины банковской редакции запрещены вне allowlist;
  personal-paths scan ловит также `~/Загрузки`, `~/Downloads`, `~/Desktop`,
  `/Users/`.
- `CONTRIBUTING.md`, `CHANGELOG.md`, шаблоны issue и PR в `.github/`.
- ROADMAP.md — дорожная карта AI/ML Edition (заменила унаследованную).

### Изменено

- Идентичность документации доведена до AI/ML Edition: README, ROADMAP,
  `docs/getting_started.md` (примеры переведены на `examples/`), гайд
  `docs/SPINE-BE-GUIDE.md` переименован в `docs/SPINE-ML-GUIDE.md`,
  `docs/README.md`, `SUPPORT.md` (каналы — GitHub Issues), `AGENTS.md`,
  `AGENTS-READERS.md`, `deploy-kit/`.
- Ссылки на локальные файлы автора (`~/Загрузки/…`) убраны из `aiml/`,
  `benchmarks/`, кейсовых ADR.
- Манифесты плагинов `aiml/plugins/` приведены к единому формату:
  `$schema` (битый внешний URL) убран, описания переменных окружения
  переехали из `env` в `env_doc` (hypothesis-router), событие `check`
  объявлено в манифесте.
- `evalio.py` плагина laguna-gb10-skills — единая копия в `lib/` (было две
  побайтно-identичные).
- Тестовые фикстуры и комментарии в `src/` очищены от банковского домена.

### Исправлено

- `control.rs`: константные regex вынесены в `LazyLock`
  (`regex_creation_in_loops` — реальная горячая точка).
- Clippy-долг форка (84 срабатывания на stable 1.98): механические классы
  зачищены, allow-список в `Cargo.toml` сокращён до обоснованных позиций.

### Удалено

- `кейсы/axiom/evidence/a4-run-wire/` (≈36 МБ, ~3300 файлов сырых
  evidence прогонов) — вынесены из дерева в архив релиза
  (`axiom-a4-run-wire-evidence.tar.zst`, см. SHA256 в примечаниях
  релиза); сводки и вердикты остаются в кейсе.
