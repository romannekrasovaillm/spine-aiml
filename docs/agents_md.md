# AGENTS.md для команд — генерация, контроль, флот

AGENTS.md — первое, что читают кодовые агенты (Claude Code, Qwen Code, OpenClaw,
Hermes, Theseus, CodeWhale) и новые разработчики в репозитории. Харнесс превращает
его из «ридми» в **канал доставки архитектурного контроля**: файл компилируется из
артефактов, проверяется на дрейф и масштабируется на флот репозиториев.

## Принцип: компиляция, не сочинение

Рукописный AGENTS.md устаревает молча (команды, инварианты, запреты дрейфуют от
истины). Харнесс генерирует машинную зону из источников:

- spine (`docs/ARCHITECTURE-SPINE.md`) → секция «Инварианты» (AD-n + Rule);
- `CONSTRAINTS.yaml` → секция «Запреты и fitness-правила»;
- манифесты (Cargo.toml, package.json, pom.xml, go.mod, pyproject.toml, Makefile) → «Команды»;
- структура каталогов, docs/adr, CI → «Карта репозитория»;
- 15 триггеров значимости → «Стоп-условия» (когда агент обязан эскалировать архитектору, A3).

## Двухзонная схема

```
# AGENTS.md — payments-core
> Рукописная зона — вне маркеров ARCH.

<!-- ARCH:GENERATED hash=ffa5… ts="2026-08-14 17:18" -->
…машинная зона (не редактировать — правьте источники)…
<!-- ARCH:END -->

## Наши договорённости      ← зона команды, refresh НЕ затирает
- коммиты на русском
```

- Нет файла → создаётся целиком. Нет маркеров → зона дописывается в конец (`appended`).
- Маркеры есть → заменяется только зона (`refreshed`), рукописное сохраняется.

## Команды

```bash
arch-ml agents-md refresh <repo>     # сгенерировать/обновить (create/refresh/append)
arch-ml agents-md lint <repo>        # свежесть (хэш входов), ссылки, заглушки; exit 1 при error
arch-ml agents-md lint-all           # прогон по реестру ~/.arch-ml/repos.txt (путь на строку)
```

В TUI: `/agentsmd <repo>` (генерация + линт). В агентном цикле модель вызывает
инструменты `agentsmd_generate` / `agentsmd_lint`.

## Дрейф-контроль

В маркер вшит `hash` входов (spine + CONSTRAINTS + факты репо). Изменился источник →
`lint` сообщает `stale` (severity error, exit 1) → `refresh` обновляет. Крон-задача
`agents-md-drift` (в `cron.example.toml`) гоняет `lint-all` по флоту и пишет сводку
в `reports/cron/`.

## Качество файла

Якорная рубрика `agents_md_quality` (в `assets/rubrics`): точность команд, покрытие
инвариантов, стоп-условия, свежесть, сигнал/шум. Оценка:
`arch-ml rubric run agents_md_quality <repo>/AGENTS.md`.

Методика для команд — скилл **`agents-md-authoring`** (плагин arch-core): границы
ответственности, норма 60–150 строк, антипаттерны.

## Цикл выкатки стандарта на флот

1. Архитектор правит источник (spine/CONSTRAINTS корпоративного шаблона).
2. `arch-ml agents-md refresh` по реестру (или handoff-пакетом через кодовые харнессы).
3. CI репозитория: `arch-ml agents-md lint .` — дрейф ломает сборку (error).
4. Еженедельный крон-дайджест покрытия и дрейфа — архитектору.
