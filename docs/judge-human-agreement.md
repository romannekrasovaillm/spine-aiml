# Протокол J-3: согласие LLM-судьи с живыми архитекторами

Ранбук для ДИТ: периодическая проверка того, что golden-эталоны калибровки
судьи (ADR-004) не расходятся с оценками практикующих архитекторов.

## Участники и процедура

- **Участников — 5 и более** практикующих solution-архитекторов (ДИТ).
  Меньше пяти — медиана неустойчива, протокол считается несостоявшимся.
- Оценка проводится **вслепую**: участник не видит ни golden-эталон, ни
  оценки судьи, ни анкеты коллег.
- Каждый участник оценивает **все документы** golden-set
  (`assets/benchmarks/golden/*.md`) по рубрике `adr_quality`.
- Формат анкеты — **тот же файл expected.yaml, что у golden**: по файлу
  `<имя-документа>.<участник>.expected.yaml` на документ:

  ```yaml
  rubric: adr_quality
  scores:
    context: 4
    decision: 5
    # … все критерии рубрики
  ```

  Анкеты собираются в отдельный каталог (вне репозитория или в
  игнорируемом подкаталоге). Неполная анкета (нет оценки хотя бы по одному
  критерию) — брак: команда упадёт с именем файла, анкету вернуть участнику.

## Прогон

```bash
arch-ml bench human-agreement \
  --golden-dir assets/benchmarks/golden \
  --humans <каталог-анкет>
```

## Как читать результат

- **(а) MAE «эталон golden vs медиана людей»** — насколько эталон расходится
  с живыми архитекторами.
- **(б) среднее MAE «человек vs медиана людей»** — уровень межчеловеческого
  согласия; это бенчмарк для (а): люди тоже расходятся между собой, и
  требовать от эталона согласия точнее этого уровня бессмысленно.
- **(в) вердикт**: если (а) ≤ (б) — расхождение эталона с людьми в пределах
  межчеловеческого разброса, эталоны валидны. Если (а) > (б) — эталон
  систематически расходится с практикой сильнее, чем практики между собой:
  **пересмотреть golden-эталоны** по спорным документам и критериям
  (таблица «документ × критерий» показывает, где именно Δ наибольшая).

Документы golden без анкет команда пропускает с warn-строкой — это сигнал,
что анкеты собраны не на весь набор.
