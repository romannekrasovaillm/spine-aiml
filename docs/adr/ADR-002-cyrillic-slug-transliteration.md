# ADR-002. Транслитерация кириллицы в слагах файлов артефактов

- Date: 2026-08-17
- Status: Accepted
- Expiry review: при появлении в заголовках не-кириллических не-ASCII
  алфавитов (китайский, арабский) — пересмотреть в сторону полноценного
  unicode-slug вместо ручной таблицы.

## Context

`kebab_slug` (`src/control.rs`) оставлял только `is_ascii_alphanumeric`:
кириллические заголовки терялись целиком. Наблюдаемые дефекты в кейсах:

- «Сегментация доверенных зон (4 зоны)» → `ADR-004-4.md` (от заголовка
  выжила цифра);
- полностью кириллический заголовок → пустой слаг → фолбэк `"adr"` →
  `ADR-005-adr.md`, `ADR-006-adr.md` в кейсе 002 и `ADR-002-adr.md`,
  `ADR-005-adr.md` в кейсе 001.

Имена ADR перестают быть навигационными: по имени файла нельзя понять тему
решения, ссылки на артефакт нечитаемы в ревью и diff. Ревью
`SPINE-REVIEW.md` (находка F-3, задача P0-4).

## Decision

1. В `kebab_slug` добавить практичную таблицу транслитерации кириллицы
   (не строгий ГОСТ): `ё→yo, ж→zh, й→y, х→h, ц→c, ч→ch, ш→sh, щ→sch,
   ы→y, э→e, ю→yu, я→ya`, остальные буквы однозначно; `ъ`/`ь` опускаются
   без порождения дефиса. Регистр сначала приводится unicode-lower, затем
   применяется таблица.
2. Фолбэк `"adr"` оставить только для действительно пустого результата
   (пустой заголовок или одни знаки препинания).
3. Существующие деградировавшие файлы кейсов переименовать в имена, которые
   породила бы исправленная функция; ссылки в `MANIFEST.json`,
   `ARCHITECTURE.md`, `CONSTRAINTS.yaml` обновить.

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| Строгий ГОСТ 7.79 система Б (`ц→cz`, `х→x`, `й→j`) | формальный стандарт | `segmentacziya`/`doverennyx` хуже читаются русскоязычными; расходится с привычными слагами |
| Внешний крейт (deunicode и т.п.) | полный unicode | новая зависимость ради таблицы на 33 символа; поведение крейта менее предсказуемо для наших заголовков |
| Оставить ASCII-only | ноль работы | сохраняется дефект: имена-обрезки (`ADR-004-4`) и коллизии фолбэка |

## Consequences

### Positive

- Детерминированные навигационные имена: `ADR-004-segmentaciya-doverennyh-zon-4-zony.md`.
- Покрыто тестами: кириллический, смешанный и пустой заголовок.

### Negative

- Переименование существующих файлов кейсов — разовая миграция ссылок.
- Таблица покрывает только кириллицу; другие алфавиты по-прежнему
  сворачиваются в дефисы (см. Expiry review).

## Reversibility

reversible. Таблица локальна в одной функции; её замена меняет только имена
будущих файлов, существующие артефакты не затрагиваются.
