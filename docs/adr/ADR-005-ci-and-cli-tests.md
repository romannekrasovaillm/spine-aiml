# ADR-005. CI-конвейер и интеграционные тесты CLI

- Date: 2026-08-17
- Status: Accepted
- Expiry review: при появлении релизного процесса (первый тег) — добавить
  сборку бинарей.

> **Update 2026-08-17 (P2-4 закрыта).** Pedantic-зачистка выполнена:
> 954 → 0 предупреждений (автофикс + ручная доработка; rustc-линты
> `dead_code`/`unused_variables`/`private_interfaces` устранены по-настоящему).
> Осознанные исключения — явный allow-список с обоснованием в `Cargo.toml`
> `[lints.clippy]` (cast-арифметика терминала, `too_many_lines` до P2-3,
> `float_cmp` в тестовых ассертах и пр.). Джоба `clippy` переведена на
> `cargo clippy --all-targets -- -D warnings`; гейт закреплён fitness-правилом
> C-20 корневого CONSTRAINTS.yaml. Оговорка пункта 2 («без -D warnings»)
> снята.

## Context

Ревью `SPINE-REVIEW.md` (находка F-7, задача P0-5):

- CI отсутствует вовсе (`.github/` нет) — 442 юнит-теста не защищают ветку.
- `assert_cmd` и `predicates` объявлены в `[dev-dependencies]`, но не
  используются: CLI-контракт (идемпотентность `arch init`, exit 1 у
  `control check`, exit 2/3 у `harness-run`, смоуки `mermaid`/`doctor`)
  ничем не покрыт.

Факты о дереве, влияющие на решение:

- `cargo clippy --all-targets` даёт ~378 уникальных предупреждений в lib
  (pedantic по AGENTS.md пока толерирован). Строгий `-D warnings` потребовал
  бы правки сотен мест — это объём отдельной задачи P2-4 ревью, а не P0-5.
- `cargo fmt --all -- --check` даёт 477 дифф-ханков по всему `src/`: без CI
  rustfmt никогда не гонялся. Fmt-гейт на таком дереве был бы красным с
  первого прогона — нужен механический baseline-коммит `cargo fmt --all`
  (семантику rustfmt не меняет).
- Объявленный MSRV 1.85 сейчас НАРУШЕН в main: `let`-цепочка в
  `src/llm/openai_compat.rs` (стабильно с 1.88) и `floor_char_boundary` в
  `src/harness.rs` (стабильно с 1.91) не дают `cargo check` на 1.85
  скомпилировать крейт. Без точечных правок MSRV-джоба была бы красной.
- Контракт `arch doctor` задокументирован (`docs/slash_commands.md`,
  `docs/theseus_hardening.md`): exit code 1 при любом вердикте Fail, а
  отсутствие ключа модели по умолчанию — Fail (`src/doctor.rs`,
  `check_api_keys`). Формулировка DoD ревью «doctor без ключей → exit 0»
  противоречит этому контракту.
- `Cargo.toml` пиннит `rust-version = "1.85"`, а `rust-toolchain.toml`
  запрашивает `stable` — MSRV-джобе нужен явный override
  (`RUSTUP_TOOLCHAIN`), иначе rustup подставит stable из toolchain-файла.

## Decision

1. `.github/workflows/ci.yml` — пять джоб на `push` в `main`,
   `pull_request` и ручной запуск: `fmt` (`cargo fmt --all -- --check`),
   `clippy` (`cargo clippy --all-targets`), `test` (`cargo test`),
   `msrv` (`cargo check` на 1.85), `audit` (`cargo audit`). Экшены —
   `dtolnay/rust-toolchain` + `Swatinem/rust-cache` (кэширует в т.ч.
   `$CARGO_HOME/bin`, поэтому установка `cargo-audit` платится раз).
2. Джоба `clippy` — БЕЗ `-D warnings` (отложенное решение): текущие ~378
   предупреждений делают строгий режим невозможным без большого диффа;
   ужесточение — задача P2-4 ревью. Джоба всё равно блокирует ошибки
   уровня deny и даёт видимое число предупреждений в логе.
3. Аудит зависимостей — `cargo audit` (устанавливается через
   `cargo install --locked` в джобе): конфиг не нужен, в отличие от
   `cargo deny` с его `deny.toml`.
4. Сборка релизных бинарей на тег — НЕ делаем (отложенное решение):
   релизного процесса и каналов дистрибуции у исследовательского проекта
   пока нет; вернёмся при первом теге.
5. `tests/cli.rs` + хелперы `tests/common/mod.rs` на уже объявленных
   `assert_cmd`/`predicates`/`tempfile`. Каждый тест изолирует дом:
   `HOME` и `XDG_CONFIG_HOME` указывают в tempdir, `ARCH_HOME` и
   API-ключи провайдеров снимаются (`env_remove`), `cwd` — tempdir, чтобы
   не подхватывался случайный `./arch-ml.toml`. Сети нет, реальный
   домашний каталог не трогается.
6. Контракт `harness-run` покрывается фейковым кодовым харнессом:
   исполняемый shell-скрипт в tempdir печатает headless JSON-контракт
   результата (`status=blocked` → exit 2; непустые
   `conflicts_with_prior_decisions` → exit 3; `complete` → exit 0) и
   прописывается в тестовый `config.toml` (`[harnesses.fake]`), который
   передаётся через `--config`.
7. Отступление от буквы DoD по `doctor` (см. Context): тест фиксирует
   РЕАЛЬНЫЙ задокументированный контракт — без единого ключа в окружении
   `arch doctor` отрабатывает без паники и трейса ошибки, печатает полный
   отчёт и завершается кодом 1 (Fail «нет ключа модели по умолчанию»).
   Смягчение семантики «нет ключа → Warn» — продуктовое изменение вне
   объёма P0-5; вынесено на решение пользователя.
8. Два нарушения MSRV устранены точечно, без смены поведения: let-цепочка
   в `normalize_reply` разнесена в плоские условия (без вложенных
   `if let` — чтобы стабильный clippy `collapsible_if` не предлагал
   вернуть let-chain), `floor_char_boundary` заменён ручным спуском по
   `is_char_boundary` с комментарием о причине.
9. Механический baseline `cargo fmt --all` — отдельным коммитом: 477
   ханков чистого переформатирования, семантика не меняется. Параллельным
   веткам P0-* при мерже после этого baseline достаточно прогнать
   `cargo fmt --all` поверх — конфликты механические.

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| clippy с `-D warnings` сразу | строгий гейт | ~378 существующих предупреждений → огромный дифф и конфликты с параллельными ветками P0-*; это задача P2-4 |
| `cargo deny` + минимальный deny.toml | лицензии, баны, адвизории в одном | новый конфиг-файл для сопровождения; `cargo audit` закрывает адвизории без конфига |
| Экшен `rustsec/audit-check` | без шага установки | ещё один сторонний экшен в цепочке поставки; `cargo install` + кэш достаточны |
| `cargo nextest` | быстрее, retries | не гоняет doctests; на 442 тестах (~11 с) выигрыш не окупает конфиг |
| Релизные бинари на тег | готовая дистрибуция | нет релизной политики; преждевременно |
| Поменять `doctor` под DoD (Fail→Warn по ключам) | exit 0 как в тексте ревью | несанкционированная смена задокументированного контракта в тестовой задаче |

## Consequences

### Positive

- Ветка защищена fmt/test/MSRV/audit гейтами; CLI-контракты из F-7
  покрыты детерминированными офлайн-тестами.
- `assert_cmd`/`predicates`/`tempfile` наконец используются — находка
  ревью закрыта.
- Фейковый харнесс задаёт воспроизводимый паттерн тестирования
  `harness-run` без живых кодовых агентов.

### Negative

- Джоба `clippy` не блокирует рост числа предупреждений (до P2-4).
- Fmt-baseline механически конфликтует с параллельными ветками P0-* —
  одна точка слияния с `cargo fmt --all` поверх; неизбежная цена введения
  fmt-гейта на никогда не форматировавшееся дерево.
- Джоба `audit` может краснеть из-за внешних адвизорий без изменений в
  нашем коде — пересмотр по факту первого такого случая.

## Reversibility

reversible. Workflow и тесты аддитивны; MSRV-правки — эквивалентные
преобразования двух выражений; fmt-baseline откатывается повторным
`cargo fmt --all` в любую сторону.
