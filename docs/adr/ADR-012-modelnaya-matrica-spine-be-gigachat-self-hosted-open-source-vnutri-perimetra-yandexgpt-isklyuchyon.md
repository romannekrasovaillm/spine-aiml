# ADR-012. Модельная матрица Spine BE: GigaChat + self-hosted open-source внутри периметра, YandexGPT исключён

- Date: 2026-08-31
- Status: Accepted

## Context

Spine BE продаётся в ДИТ банков и работает в регулируемом контуре. Вопрос
модельной матрицы — вопрос trust boundary: какие LLM-провайдеры допустимы,
где они развёрнуты и чьи API-ключи никогда не покидают периметр.

Факты кодовой базы на точке форка (проверено):

- Все LLM-провайдеры Spine — OpenAI-совместимые endpoint'ы: адаптеры
  `deepseek`, `kimi`, `glm` + generic `openai_compat` (`src/llm.rs:3`,
  `src/llm/`). Конфигурация через `[models.*]` в `config.toml`
  (`base_url`, `model`, `api_key_env`) — self-hosted модель с
  OpenAI-совместимым API подключается конфигом, без кода.
- GigaChat в кодовой базе отсутствует (0 вхождений по grep).
- Внешние API провайдеров (api.deepseek.com, api.z.ai, api.kimi.com) —
  дефолт апстрима, неприменимый для контура ДИТ с данными.

Решение владельца продукта: YandexGPT не используется — это продукт
конкурента; матрица — GigaChat и китайские open-source модели внутри
периметра банка.

## Decision

Модельная матрица Spine BE состоит из двух групп, обе — внутри периметра
банка в продуктиве:

1. **GigaChat** (Сбер) — приоритетный провайдер. Облачная площадка
   допустима только для разработки без конфиденциальных данных;
   продуктив в контуре ДИТ — on-prem/закрытая поставка [ТРЕБУЕТ ПРОВЕРКИ:
   условия on-prem поставки и варианты API — актуальная документация
   GigaChat недоступна для автоматической сверки на дату ADR; закрыть при
   walking-skeleton адаптера]. Если GigaChat API не полностью
   OpenAI-совместим — отдельный адаптер по образцу `src/llm/deepseek.rs`.
2. **Китайские open-source модели, self-hosted** (open weights: DeepSeek,
   GLM, Kimi, Qwen — совместимость конкретных весов с self-hosting
   проверить на интеграционном тесте) за OpenAI-совместимым шлюзом
   (vLLM и аналоги) — подключаются generic `openai_compat` конфигом.

**YandexGPT исключён из матрицы** — продуктовое ограничение владельца:
продукт конкурента не входит в Spine BE ни как провайдер, ни как
fallback. Исключение фиксируется и в продуктовых CONSTRAINTS
(отрицательная fitness-функция: отсутствие yandexgpt в конфигах и коде).

Внешние облачные API (api.deepseek.com, api.z.ai, api.kimi.com) —
допустимы только вне контура заказчика, для разработки и бенчмарков без
конфиденциальных данных.

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **GigaChat + self-hosted open-source (принято)** | политика владельца; две независимые группы провайдеров (устойчивость к недоступности одного); self-hosted — нулевой вывод данных за периметр; open weights — воспроизводимость | GigaChat on-prem — условия поставки не подтверждены [ТРЕБУЕТ ПРОВЕРКИ]; self-hosted требует GPU-бюджета ДИТ; операционная нагрузка на инфраструктуру заказчика |
| Только self-hosted open-source | нулевая зависимость от внешнего вендора; полный контроль | нет управляемого варианта «из коробки» для ДИТ без GPU-инфраструктуры; GigaChat — знакомое ДИТ имя, его исключение сужает продажи |
| YandexGPT в матрице | крупнейший российский LLM-вендор, широкая узнаваемость | нарушает решение владельца (конкурент); отвергну безусловно |
| Внешние API китайских провайдеров как есть (дефолт апстрима) | нулевая работа | данные архитектурных сессий банка уходят за периметр — неприемлемо для ДИТ |

## Consequences

### Positive

- Единый продуктовый ответ ДИТ на вопрос «куда уходят данные»: никуда,
  обе группы провайдеров внутри периметра.
- Self-hosted группа не требует нового кода (openai_compat) —
  дифференциация почти бесплатно.
- Матрица проверяема fitness-функциями: отсутствие yandexgpt, отсутствие
  внешних base_url в продуктовых пресетах.

### Negative

- GigaChat-адаптер — новая работа; если API не OpenAI-совместим, нужен
  отдельный модуль + OAuth-токены (ключи уже в схеме `api_key_env`, но
  жизненный цикл OAuth-токенов GigaChat сложнее статических ключей).
- Self-hosted для ДИТ — GPU-бюджет и MLOps-зрелость заказчика; не у всех
  банков она есть (сужение сегмента, митигируется наличием GigaChat).
- Исключение YandexGPT закрыто для пересмотра политикой владельца —
  если рынок изменится, решение переписывается явным ADR-переопределением,
  а не тихой правкой.

## Reversibility

**costly**: матрица фиксируется в продукте, доке и демо-конфигах;
исключение провайдера после продаж — переписывание контрактов и
пресетов. Смена внутри допустимых групп (добавление ещё одной
open-source модели) — reversible, конфиг.
