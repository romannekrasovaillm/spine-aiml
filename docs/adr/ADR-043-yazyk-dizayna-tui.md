# ADR-043. Язык дизайна TUI: справка, черновик, деградация оформления

- Date: 2026-09-12
- Status: Accepted

## Context

TUI (ratatui + crossterm, `src/tui/`) развивался функционально: диалог,
правая панель вкладок, модальные пикеры, очередь, индикатор контекста,
фоновые субагенты. Дизайн-слой при этом не следовал конвенциям
терминальной культуры, и это дало несколько наблюдаемых дефектов:

- **Справки по клавишам не было.** `?` не обрабатывался; `/help` печатал
  каталог слэш-команд в диалог, то есть засорял контекст агента. Строка
  подсказок перечисляла только F-клавиши, поэтому вкладки переключались
  исключительно ими (F-клавиши как единственный путь), а частые действия в
  подсказках не видны.
- **`Esc` выходил из приложения всегда**, в том числе при непустом поле
  ввода: промах по клавише стоил набранного текста — молча, без
  предупреждения и без возврата.
- **Оформление было жёстко захардкожено** в truecolor-виде: `NO_COLOR` и
  `TERM=dumb` игнорировались, в 16-цветном терминале палитра вырождалась,
  светлой темы не было, а структурные глифы (брайлевский спиннер, `▰▱`,
  эмодзи `🧠` в бейдже модели) не имели ASCII-двойника.
- **Минимальный размер окна не был объявлен**: при 60×14 и ниже панели
  схлопывались, и на экране был мусор вместо сообщения.
- **Полноэкранная заставка** стоила лишнего нажатия, отдавала первый экран
  декору и делала главный сценарий недоступным с первого кадра.

Ревью проведено по набору скиллов `tui-design-skills` (принципы дизайна
TUI, раскладка и компоненты, цвет и темы, клавиатура, совместимость и
доступность, UX-аудит): отчёт с уровнями проблем — `docs/tui-ux-review.md`.

## Decision

1. **Реестр клавиш — единый источник.** `src/tui/keymap.rs` объявляет
   каждое действие один раз (контекст, клавиши, подпись, описание, раздел,
   приоритет). Из него собираются строка подсказок статус-бара и справка
   `?`. Модальные слои (справка, просмотрщик, пикер) объявляют `q`/`Esc`/`?`
   сами — фокус заперт, глобальные клавиши наследует только чат; полный
   список переопределений фиксируется тестом.
2. **`?` открывает оверлей справки**, а не печатает текст в диалог:
   группировка по задачам, прокрутка, закрытие `?`/`Esc`/`q`. `/help`
   остаётся каталогом команд агента — это разные вопросы.
3. **`Esc` не выходит из приложения, пока есть что терять.** Три роли по
   приоритету: прервать ход → отложить/вернуть черновик → выход. Черновик
   живёт в одном слоте, в пустом поле видно напоминание о возврате.
4. **Оформление деградирует по возможностям терминала.** Три яруса цвета
   (truecolor → 256 → ANSI-16 → без цвета), светлая палитра, ASCII-фолбэк
   рамок и глифов, статичные индикаторы по ssh. Приоритет настроек:
   флаги CLI → окружение → `[tui]` конфига → эвристика. Каждый ярус
   проверяется тестом, контраст палитр — по WCAG.
5. **Заставки нет.** Чат — стартовый и единственный рабочий экран,
   логотип — первый блок диалога; пустое состояние объясняет, что делать.
6. **Минимальный размер объявлен (60×16)**: меньше — заглушка с текущим и
   требуемым размером. Экран фатальной ошибки рисуется всегда.
7. **Сдержанность хрома.** Рамок на экране две (диалог и панель вкладок):
   поле ввода без рамки, состояние хода/очереди — строкой над вводом;
   градиент логотипа убран в пользу одного акцента.

## Consequences

**Хорошо.** Пользователь видит, что нажать, прямо на экране (в т.ч. в 80
колонках), может выйти, не потеряв текст, и получает читаемый интерфейс в
`LANG=C`, 16-цветном терминале, tmux и по ssh. Рассинхрон «подсказки vs
код» ловится тестами, а не эксплуатацией.

**Цена.** Дизайн-изменения затрагивают существующие тесты кадров
(заставка, рамка ввода, пустой лог) — они обновляются вместе с кодом, а не
отдельно. Реестр клавиш требует дисциплины: новая клавиша без записи в
`BINDINGS` не попадёт ни в подсказку, ни в справку — это заметно сразу.

**Отступления, принятые осознанно.** `Esc` умеет выходить из приложения
(при пустом поле и пустом слоте черновика) — конвенция допускает выход по
`Esc` на корневом экране, а `q`/`Ctrl+C` остаются безусловными. F-клавиши
сохранены как способ прыжка в конкретную вкладку, но больше не единственный
путь: есть `Tab`/`Shift+Tab`.

**Не сделано (кандидаты).** Автодополнение слэш-команд — по-прежнему ghost-
подсказка и `Tab`, без выпадающего списка; поиск по диалогу (`/`) не
введён — слэш занят слэш-командами; high-contrast тема не заведена;
`--accessible` (линейный режим для скринридеров) не реализован — headless
`arch-ml run` остаётся ближайшим аналогом.
