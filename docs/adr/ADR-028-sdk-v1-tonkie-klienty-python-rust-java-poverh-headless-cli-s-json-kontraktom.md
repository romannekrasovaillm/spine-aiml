# ADR-028. Spine-BE SDK v1 — тонкие клиенты (Python/Rust/Java) поверх headless CLI с JSON-контрактом

- Date: 2026-09-03
- Status: Accepted

## Context

Команды просят встраивать Spine-BE в свои продукты и процессы: CI-гейты,
pre-commit, боты, кодовые агенты. До этого взаимодействие было только
человеческим (TUI) либо текстовым парсингом stdout — хрупким и не
версионируемым. Нужен стабильный машиночитаемый контракт и клиенты на
языках команд (Python, Rust, Java).

Варианты: (а) сетевой демон + RPC-клиенты — новая поверхность ИБ,
деплой, аутентификация; (б) SDK, линкующиеся с ядром — только для Rust,
тащит внутренности харнесса; (в) тонкие клиенты поверх headless CLI —
процесс `arch-be` как граница, stdout/exit code как протокол.

## Decision

Вариант (в). Ядро получает флаг `--json` в точках машинного потребления:
`control check --json` (однострочный `FitnessReport`), `archify
validate|deliver|compare --json` (сырой receipt Archify CLI, уже
JSON-native). Контракт зафиксирован в `sdk/CONTRACT.md` (версия 1):
JSON-схемы, exit-коды, типы ошибок, фикстуры. SDK (`sdk/python`,
`sdk/rust`, `sdk/java`) — тонкие клиенты: запуск процесса без shell,
клиентский таймаут, разбор stdout, единая форма API и ошибок
(`BinaryNotFound`, `Timeout`, `ProcessFailed`, `ContractViolation`).
`control check` с `passed=false` — валидные данные, не исключение.
Java-SDK несёт встроенный мини-парсер JSON (ноль внешних зависимостей —
в контуре банка нет Maven Central).

## Consequences

- Плюс: нулевая новая сетевая поверхность (ИБ-контур не меняется);
  контракт версионируется отдельно от бинаря; языковые SDK независимы
  друг от друга и от релизного цикла ядра; тесты SDK — живые, против
  собранного бинаря (Python 19, Rust 17, Java 82 проверки зелёные).
- Минус: SDK требует установленный `arch-be`; стоимость запуска процесса
  на вызов (для гейтов приемлема); `run()` не стримит.
- Догма: ломающие изменения контракта (переименование/удаление полей,
  смена exit-кодов) — только major-версией `sdk/CONTRACT.md` с миграцией
  всех трёх SDK; добавление полей — свободно.
