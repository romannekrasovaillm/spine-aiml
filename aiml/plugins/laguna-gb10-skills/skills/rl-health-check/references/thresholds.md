# Пороги для диагноза RL (GRPO, модели 1.5B–3B, лесенка Laguna)

Откалиброваны на v12 (1.5B, 500 шагов, группы 4×2). Для другой длины
ответов/группы — корректировать, но порядок величин тот же.

| Метрика | Здорово | Внимание | Стоп |
|---|---|---|---|
| энтропия (по шагу) | 0.9–1.5 | 0.6–0.9 более 20 шагов подряд | < 0.5 (коллапс) или > 2.5 (шум/сломан формат) |
| KL к инициализации | ≤ 0.001 | 0.001–0.01 | > 0.01 (и/или сдвиг ppl_general) |
| clip-fraction | 0–0.05 | 0.05–0.2 | > 0.2 (lr слишком велик) |
| ppl_general, отклонение от 1-го замера | ≤ 0.5% | 0.5–2% | > 2% (забывание) |
| reward, тренд Q4 − Q1 | ≥ 0 | −0.05…0 | < −0.05 (деградация) |
| pass-rate (reward ≥ 1) | ≥ 30% | 10–30% | < 10% (сигнал слишком редкий) |
| длина ответа, тренд | ± 15% | +15…+50% | > +50% (length hacking) |
| tool-calls / роллаут | 1–2 | 2–3 или 0.5–1 | > 3 или < 0.5 |
| доля роллаутов с ошибкой парсинга | < 2% | 2–5% | > 5% |

Замечания:
- Энтропия считается на токенах ответа; на tool_response не считать.
- KL ≈ 0 вместе с clip = 0 — не ошибка, а консервативный апдейт; это
  плохо только если целью был рост.
- ppl_general нужен именно как детектор забывания; его абсолютное
  значение (v12: 50.8) сравнивать между моделями нельзя.
- pass-rate по шагу с группой 8 роллаутов принимает значения 0, 12.5, …,
  100% — «колебания 0–75%» это дискретность, а не нестабильность.
