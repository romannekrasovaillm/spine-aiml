# Схема карточки гипотезы (HYPOTHESIS.md)

Одна карточка — один каталог `<hypotheses>/<id>/HYPOTHESIS.md`. Рядом
можно класть `notes/`, ссылки на артефакты, но фронтматтер — единственное,
что читают скрипты.

## Фронтматтер (YAML, плоский — без вложенных объектов кроме triggers)

```yaml
id: laguna-gb10-ladder            # slug, = имя каталога
title: Лесенка маленьких моделей на GB10
state: latent                      # fleeting | latent | active | project | archived
created: 2026-09-13
last_touched: 2026-09-13
source: "Отчёт v12_qwen25-15b_s42 (техотчёт лабы), 13.09.2026"
source_path: ~/reports/Отчёт_v12_15b_s42_...docx
owner: me
triggers:
  files:      ["rollouts_log.jsonl", "eval_results_*.json", "*_checkpoint_*.pt"]   # glob по именам в проекте, вес 3
  keys:       ["LAGUNA_MEM_FRACTION", "vllm_gpu_memory_utilization"]                # ключи конфигов/env, вес 3
  deps:       ["vllm", "flex-attn"]                                                 # зависимости (requirements/pyproject/Cargo), вес 2
  words:      ["GB10", "DGX Spark", "CPT", "GRPO", "лесенка"]                       # слова намерения/README, вес 1
skills:   [laguna-ladder-run, ood-stage-eval, cpt-template-check, rl-health-check, ladder-interpretation-report]
plugins:  [laguna-gb10-skills]
projects: []                        # где применялась: [{name, date}] заполняет --touch
related:  []                        # id других карточек
promote_when: "появился доступ к боксу с GB10 и задача дообучить модель ≤3B под домен"
decay_months: 6                     # fleeting→archived без касаний
```

Веса триггеров по умолчанию: files 3, keys 3, deps 2, words 1. Балл
карточки = сумма весов уникальных совпавших триггеров; порог по умолчанию
в `card_match.py` — 2 (одно слово не поднимает карточку, один файл —
поднимает).

## Тело (Markdown, свободное, но с этими разделами)

```markdown
## Намерение
Одна-две фразы: что хочу уметь/понять и зачем.

## Почему это может пригодиться
Сценарии, в которых гипотеза станет полезной; чем она отличается от того,
что уже есть в библиотеке.

## Что сделало бы это проектом
Конкретное условие (дублирует promote_when, но с пояснением).

## Что выведено
Скиллы/плагины/заметки с одной строкой «что делает».

## Открытые вопросы
Что не проверено; что нужно узнать, прежде чем тратить время.

## Журнал
- 2026-09-13 — заведена из отчёта v12; выведено 5 скиллов.
```

## Состояния

| Состояние | Смысл | Где живут скиллы |
|---|---|---|
| fleeting | мимолётный интерес, триггеры набросаны | теплица |
| latent | пригодится, триггеры выверены | теплица |
| active | применяется в текущей работе | доменный ярус |
| project | выросло в отдельный проект | репо проекта; карточка хранит ссылку |
| archived | давно не трогали | теплица, исключено из роутинга по умолчанию |

Переходы вверх — по факту использования (`--touch` ≥ 2 разных проектов →
предложение `active`), вниз — по времени (`decay_months`). Скрипты
переходы *предлагают*; выполняет пользователь.
