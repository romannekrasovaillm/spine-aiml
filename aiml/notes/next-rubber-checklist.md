## H2.1 — RL-через-харнесс: от «петля работает» к «обучается»
**Блокер:** GPU ≥ 40GB + модель 3B+ + veRL 0.4.0 (стенд). Петля уже проверена
на 0.5B (`benchmarks/spine-vs-claude/rl/grpo_manual.py`, v2-фиксы).

1. [ ] Поднять стенд (3B+ на 40GB, veRL-стек по памяти `verl-version-compatibility`).
2. [ ] Конфиг прогона: n=8, temp=1.5, LR подобрать, шагов 24 → 200+.
3. [ ] Reward: плотный (structural + exact); при малом n — global baseline
       (REINFORCE) вместо group-relative advantage (иначе advantage≈0).
4. [ ] Мониторинг: тренд mean_reward + энтропия (mode-collapse порог <0.1).
5. [ ] Критерий успеха: устойчивый рост reward за прогон, а не «петля не падает».
