Это самостоятельный инженерный блок — H1-финальная карточка, не срочно.

   (accuracy по маршруту Fast/Standard/Critical).
2. Порог уверенности + эскалация: низкая уверенность локальной модели → фронтир.
3. Страховка: Critical-изменение, ошибочно ушедшее по Fast — аудируемое событие.

**Точка интеграции** (когда появятся веса): `[concept]`/`[significance]` конфиг
+ `src/control.rs` significance-ско́ринг — добавить ветку «локальная модель +
эскалация». Сейчас — спеку не пишу кодом, т.к. модели нет на машине.
