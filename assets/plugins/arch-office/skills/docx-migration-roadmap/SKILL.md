# План миграции / трансформации (docx)

План миграции отвечает «как переезжаем, не уронив прод». Главная проверка —
волновая декомпозиция: каждая волна самостоятельно ценна и обратима.

## Железные правила

- Волна = самостоятельная ценность: перевод «всего разом» (big bang) —
  красный флаг; если big bang неизбежен, это отдельно обосновывается.
- У каждой волны: состав, зависимости от предыдущих волн, критерии входа
  (что должно быть готово) и выхода (как поймём, что переехали),
  план отката именно этой волны.
- Данные — отдельная глава у каждой волны: что переносим, сверка
  (реконсиляция), кто отвечает за расхождения.
- Параллельная эксплуатация: как старый и новый контуры сосуществуют
  (strangler-фасад, двойная запись/чтение), как выключаем двойной режим.
- Нагрузка и сезонные запреты: волны не ставятся в пики/заморозки
  (отчётные даты банка) — календарные ограничения фиксируются явно.
- Вывод из эксплуатации старого — тоже волна с критериями; «потом
  выключим» без критериев означает «никогда».

## Структура (фиксированная)

1. О документе (связь с концепцией/SAD, владельцы программы).
2. Драйвер миграции и критерии успеха программы.
3. Стратегия: волновая модель, strangler-подход, точки переключения.
4. Волны (на каждую: состав, зависимости, вход/выход, данные, откат).
5. Перенос данных и реконсиляция (сводно).
6. Календарные ограничения (пики, заморозки, отчётность).
7. Операционная готовность (мониторинг, поддержка, обучение).
8. Риски программы (связь с `xlsx-risk-register`).

## Процедура

1. Собери зависимости (стыки из `xlsx-integration-matrix`, каталог систем).
2. Нарежь волны: сначала малорисковые/учебные, критичные — после доказанных.
3. Скелет `references/docx_migration_roadmap_gen.py` (python-docx):
   заполни структуры, `python3 docx_migration_roadmap_gen.py migration.docx`.
4. Прочитай назад, сверь с чек-листом.

## Чек-лист приёмки

- У каждой волны есть критерии входа/выхода и собственный план отката.
- Перенос данных имеет владельца сверки и допуск расхождений.
- Календарные ограничения учтены (нет волн в запретные окна).
- Последняя волна — вывод legacy с критериями отключения.
