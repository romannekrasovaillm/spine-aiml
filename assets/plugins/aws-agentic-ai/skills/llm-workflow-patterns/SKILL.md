# LLM-workflows: 5 паттернов (AWS PG, 2026)

Вызова LLM недостаточно — модель встраивается в структурный workflow с инструментами, памятью, планированием. Паттерны композабельны (гибриды — норма).

## 1. Prompt chaining

Декомпозиция в последовательные LLM-шаги; выход шага — вход следующего. Когда: задача превышает глубину одного вызова; нужна прозрачность промежуточных результатов (аудит!); внешняя валидация между шагами. Примеры: «найди → извлеки факты → ответь», «сгенерируй план → код → тесты → объясни». Оркестрация: Step Functions/Lambda/agent runner.

## 2. Routing

LLM-классификатор направляет вход специализированному агенту/инструменту. Когда: многодоменный ассистент (фронт-дор предприятия); нормализация входа перед специализированным workflow; выбор инструмента. Качество диспетчера = качество системы; fallback-маршрут «не понял» обязателен.

## 3. Parallelization

Независимые подзадачи конкурентно (несколько LLM-вызовов/агентов), агрегация программная. Когда: подзадачи независимы; нужно разнообразие рассуждений (голосование); скорость критична. Scatter-gather. Ловушка: агрегация противоречий — правило разрешения заранее.

## 4. Orchestration (orchestrator-workers)

Мета-агент декомпозирует цель и делегирует worker-агентам (роль/инструменты/промпт свои), следит за прогрессом, синтезирует. Когда: подзадачи разнородны (план/исследование/реализация/тест); ролевая модель (PM/dev/reviewer). Иерархия допустима. Цена: стоимость и latency координации.

## 5. Evaluator / reflect-refine

Генератор + отдельный критик-оценщик (возможно, другая модель); цикл до порога качества. Когда: субъективное качество или объективные критерии; регулируемый/клиентский домен; HITL дорог → автономная валидация. Детекция галлюцинаций, red-team/blue-team, code review.

## Банковский маппинг

- Разбор документа на сделку: chaining с аудируемыми промежуточными (Evidence Bundle!).
- Фронт-агент банка: routing по доменам (платежи/кредиты/каналы).
- Архитектурное решение: parallelization вариантов + evaluator по рубрике (`rubric_evaluate`) — reflect-refine прямо в харнессе.
