# Паттерны агентов AWS: обзор (PG: Agentic AI patterns, 2026)

Три принципа агентности: **asynchronous** (событийная среда), **autonomy** (действует сам), **agency** (действует от имени пользователя к цели). Треугольник: perception → reason → action.

## Десять паттернов

| Паттерн | Суть | Когда | Ограничения |
|---|---|---|---|
| Basic reasoning | LLM в цикле рассуждения без внешних вызовов | Классификация, драфты, анализ | Нет инструментов/данных — галлюцинации |
| Retrieval-augmented (RAG) | + семантический поиск по знаниям | Доменные ответы, справочники | Качество индекса = качество ответа |
| Tool-based (functions) | LLM вызывает функции/API | Действия в системах | Схемы инструментов, идемпотентность |
| Tool-based (servers/MCP) | Инструменты как серверы (MCP) | Много команд/инструментов | Управление серверами, безопасность |
| Computer-use | Управление UI/ОС как человек | Legacy без API (!) | Хрупкость, скорость, безопасность |
| Coding | Код: контекст IDE, правки, тесты | Разработка | Нужны гейты и песочницы |
| Speech/voice | Голосовые интерфейсы | Кол-центр, IVR | Latency, barge-in, ASR-ошибки |
| Workflow orchestration | Центральный координатор субагентов | Процессы предприятия | Единая точка логики |
| Observer/monitoring | Наблюдает и реагирует на потоки | Опс, дрейф, комплаенс | Ложные срабатывания |
| Multi-agent collaboration | Пиринговая координация равных | Исследования, эмерджентность | Стоимость, предсказуемость |

## Выбор (банк)

- «Спроси wiki» → RAG; «сделай в системе» → tool-based; «старая АБС без API» → computer-use (с fitness-гейтами!); «процесс согласования» → workflow orchestration; «сложное исследование» → multi-agent.
- Каждый агент в каталоге: паттерн, владелец, инструменты, уровень автономии (R0–R5, навык `significance-routing`), evals.
- Агент = production-актив: IBM ADLC поверх (версии промптов, drift-мониторинг, kill switch).
