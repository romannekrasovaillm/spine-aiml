# AWS Agentic AI — источник и карта гайда

Гайд: «Agentic AI patterns and workflows on AWS», AWS Prescriptive Guidance, 2026
(авторы: Aaron Sempf, Andrew Hooker).
URL: https://docs.aws.amazon.com/prescriptive-guidance/latest/agentic-ai-patterns/introduction.html
PDF: https://docs.aws.amazon.com/pdfs/prescriptive-guidance/latest/agentic-ai-patterns/agentic-ai-patterns.pdf (85 стр.)

## Структура гайда → скиллы плагина

- Agent patterns (10 паттернов: basic reasoning, retrieval-augmented, tool-based functions/servers, computer-use, coding, speech/voice, workflow orchestration, observer/monitoring, multi-agent collaboration) → `agent-patterns-overview`, `multi-agent-collaboration`.
- LLM workflows (prompt chaining, routing, parallelization, orchestration, evaluator/reflect-refine) → `llm-workflow-patterns`, `reflect-refine-loops`.
- Agentic workflow patterns (prompt chaining saga, routing dynamic dispatch, parallelization scatter-gather, saga orchestration, evaluator loops) → `saga-orchestration-agents`.
