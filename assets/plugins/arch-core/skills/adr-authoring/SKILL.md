# ADR-дисциплина

Architecture Decision Record — короткий документ, фиксирующий ОДНО решение с контекстом и последствиями. Цель — не бюрократия, а воспроизводимость: через 2 года любой должен понять, почему выбрали именно так.

## Железные правила

- ADR пишется **до реализации**, ревьюится в том же PR, что и код.
- Номера не переиспользуются и не перенумеровываются; отмена — через статус `Superseded by ADR-NNN`, не удаление.
- Альтернативы обязательны: «мы не рассматривали ничего другого» = решение не обосновано.
- Отрицательные последствия обязательны: решение без минусов — маркетинг, а не архитектура.
- Обратимость оценивается явно: `reversible` / `costly` / `irreversible` + обоснование.

## Процедура

1. Создай файл: инструмент `adr_new` (или `/adr new <title>`) — номер и шаблон автоматически.
2. Context: силы и ограничения (NFR, регуляторика, существующий ландшафт), а не пересказ задачи.
3. Decision: что именно решено, одним абзацем — без «как».
4. Alternatives Considered: таблица вариант / плюсы / минусы / почему отвергнут.
5. Consequences: Positive и Negative (обе секции непустые).
6. Reversibility: что стоит откат; триггер пересмотра (expiry/условие).
7. References: спеки, ADR-зависимости, внешние источники (версии технологий — проверены `web_fetch`, не из памяти модели).
8. Статус `Proposed` → после ревью `Accepted`; при замене — новый ADR со связкой `Supersedes ADR-NNN`.

## Чек-лист

- [ ] Создан до старта реализации
- [ ] ≥2 альтернативы с причинами отказа
- [ ] Заполнены отрицательные последствия
- [ ] Обратимость оценена (reversible/costly/irreversible)
- [ ] Есть условие/срок пересмотра
- [ ] Версии названных технологий проверены из внешних источников
- [ ] Оценка по рубрике `adr_quality` ≥ 3.5 (`rubric_evaluate`)

## Антипаттерны

- ADR задним числом («задокументировать то, что уже написали») — красный флаг аудита.
- ADR-эпос на 10 страниц: решение теряется; >1 страницы — разбить на несколько ADR.
- «Выбрали Kafka, потому что она лучшая» — без критериев сравнения.
- Изменение старого ADR вместо Superseded-цепочки.

Шаблон: `references/adr-template.md`. Оценка качества: рубрика `adr_quality`.
