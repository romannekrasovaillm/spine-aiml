# AGENTS.md для команд и их агентов

AGENTS.md — первое, что читают кодовые агенты (Claude Code, Qwen Code, OpenClaw, Hermes, Theseus, CodeWhale) и новые разработчики. Для архитектора это **control plane**: единственный канал, гарантированно попадающий в контекст любого агента в любом репозитории.

## Принцип: компиляция, не сочинение

AGENTS.md генерируется из источников истины (spine-инварианты, CONSTRAINTS.yaml, манифесты, карта репо) — `arch-ml agents-md refresh <repo>`. Сгенерированный = обновляемый, проверяемый (`lint`), не дрейфующий (living spec). Руками пишется только то, чего нет в артефактах (договорённости команды).

## Двухзонная схема

- `<!-- ARCH:GENERATED hash=… ts=… -->` … `<!-- ARCH:END -->` — машинная зона: команды, инварианты (AD-n + Rule), запреты, карта, стоп-условия эскалации. Не редактировать — правь источники.
- Вне маркеров — зона команды: стиль коммитов, контакты владельцев, локальные договорённости. `refresh` её не трогает (тестом гарантировано).

## Состав машинной зоны (что несёт ценность)

1. **Команды** (сборка/тест/линт, CI) — извлечены из манифестов: агент не угадывает.
2. **Инварианты** — из spine: что нарушать нельзя, с проверяемым Rule.
3. **Запреты** — из CONSTRAINTS.yaml (fitness): `arch-ml control check` в CI.
4. **Стоп-условия** — 15 триггеров значимости: когда агент ОБЯЗАН остановиться и эскалировать (A3). Это против «агент тихо сменил API-контракт».
5. **Ссылки** на spine/ADR — читать решения до изменения затронутых мест.

## Флот репозиториев

- Реестр `~/.arch-ml/repos.txt` (путь на строку) → `arch-ml agents-md lint-all` — свод свежести/проблем, exit 1 при error (в CI/крон `agents-md-drift`).
- Дрейф-детектор: хэш входов в маркере; изменился spine/CONSTRAINTS → lint говорит `stale` → refresh.
- Качество файла — якорная рубрика `agents_md_quality` (`rubric_evaluate`).
- Выкатка нового стандарта: правим корпоративный источник → refresh по флоту → линт в CI подтверждает.

## Границы ответственности (что НЕ в AGENTS.md)

- Полные спеки — только ссылки (AGENTS.md — не дата-лейк).
- Секреты и внутренние URL с доступами — никогда.
- То, что выводимо из кода (структура пакетов) — краткая карта, не дубль.

## Антипаттерны

- AGENTS.md на 900 строк — агенты не читают простыни (бюджет контекста!); норма 60–150 строк.
- Сочинённый вручную и устаревший («сборка: make all», а Makefile год как удалён) — хуже, чем отсутствие: детектор `stale` на то и есть.
- Отсутствие стоп-условий — агент решает архитектурные вопросы молча.
