# ARCHITECTURE-SPINE — <инициатива>

Позвоночник инвариантов: только решения, по которым независимые исполнители
могут разойтись несовместимо. Тест: «могут ли две единицы уровнем ниже,
построенные независимо, выбрать несовместимо?» — нет → в Deferred.

## Inherited Invariants

- Из initiative-spine: AD-2 (форматы id), AD-5 (шина событий). Родительский
  spine — read-only; локальное переопределение запрещено, конфликт — наверх.

## AD-1. Единый протокол межсервисных команд

Binds: все сервисы контура
Prevents: зоопарк протоколов (REST/gRPC/события наугад) на одних и тех же стыках
Rule: `grep -rE "grpc|rest" services/*/contract.yaml` согласован с реестром; контрактные тесты в tests/contracts зелёные
Status: Accepted

## AD-2. Идемпотентность всех команд списания

Binds: платёжный оркестратор, ядро, хаб
Prevents: двойные списания при ретраях сети и повторной доставке событий
Rule: каждый handler списания принимает idempotency-key и покрыт тестом повторной доставки; `grep -L "idempotency" services/*/handlers/*.rs` пуст
Status: Accepted

## Deferred

- Выбор вендора шины событий — причина: нагрузочные тесты не завершены;
  условие возврата: результаты стенда, не позднее конца квартала.
