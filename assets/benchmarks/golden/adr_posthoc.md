# ADR-006. Разделение монолита на два сервиса

- Дата: 2026-08-14
- Статус: Accepted

## Контекст

Разделение выполнено в марте этого года: сервис заказов и сервис склада
работают в production уже полгода. Документ написан задним числом для
проектной документации. Исходная проблема была в замедлении релизов.

## Варианты

При разделении рассматривали модульный монолит, но выбрали отдельные
сервисы. Причины уже никто не помнит точно. Статус-кво не оценивался.

## Последствия

Плюсы: независимые релизы двух команд.
Минусы: усложнение поддержки.

## Обратимость

Решение обратимое.
