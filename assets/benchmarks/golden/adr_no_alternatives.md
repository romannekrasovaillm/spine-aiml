# ADR-003. Кэширование каталога товаров

- Дата: 2026-08-12
- Статус: Proposed

## Контекст

Каталог — 180 тысяч товарных карточек; 96 % запросов — чтение; p75
выборки карточки из базы — 140 мс, при распродажах база чтений упирается
в диск. Ограничения: устаревание цен недопустимо дольше 60 секунд
(требование отдела продаж), память на узлах ограничена 8 ГБ. Цена
бездействия: к ноябрю каталог станет узким местом распродажи.

## Решение

Внедряем распределённый кэш с инвалидацией по событию изменения цены.
Другие варианты не рассматривались: решение очевидно.

## Последствия

Плюсы: p75 чтения упадёт примерно до 5 мс, база чтений разгрузится.
Минусы: усложнение поддержки (инвалидация кэша).

## Обратимость

Решение обратимое.
