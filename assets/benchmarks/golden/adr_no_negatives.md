# ADR-004. Полнотекстовый поиск по каталогу

- Дата: 2026-08-12
- Статус: Accepted

## Контекст

Поиск по каталогу сейчас — простые запросы по подстроке, релевантность
низкая, жалобы пользователей растут. Точные метрики жалоб не собирали.

## Варианты

Рассмотрели выделенный поисковый движок и улучшение текущих запросов.
Выбрали движок — он лучше ранжирует. Статус-кво не оценивали.

## Последствия

Релевантный поиск повысит конверсию витрины. Появятся синонимы и
устойчивость к опечаткам. Поисковый индекс обновляется за секунды.
Команда получит современный инструмент с богатой экосистемой и хорошей
документацией.

## Обратимость

Решение обратимое.
