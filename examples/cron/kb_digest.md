# Cron-задача: дайджест новых материалов базы знаний (kb-digest)

Ты — дежурный агент харнесса. Собери дайджест материалов локальной базы
знаний архитектора, появившихся или изменившихся за последние сутки.

## Каталоги базы знаний

(сверься с `[knowledge] dirs` в config.toml; типичные значения — ниже)

- `~/knowledge/architecture`
- `~/knowledge/papers`
- `~/knowledge/skills`

## Шаги

1. Через `bash` найди свежие файлы (подставь каталоги из config.toml; тильду раскрывай через `$HOME`):
   `find $HOME/knowledge/architecture $HOME/knowledge/papers $HOME/knowledge/skills -type f \( -name '*.md' -o -name '*.txt' \) -mtime -1 | head -200`
2. Для каждого файла (до 30 самых свежих) прочитай начало (`head -60`)
   и выпиши одной строкой: что это и зачем архитектору.
3. Сгруппируй по темам (SDD/пост-тренинг/агенты/банковская архитектура/прочее),
   отсортируй внутри тем по убыванию пользы. Пустые дни честно помечай:
   «новых материалов нет» — не выдумывай.
4. Сохрани дайджест в отчёт и допиши ссылку на него в индекс
   `reports/cron/INDEX.md` (создай, если нет).

## Формат отчёта

Markdown: заголовок с датой, сводка одним абзацем, тематические секции
со строками «файл — суть». В конце — headless JSON-статус:

```json
{"status": "complete | partial | blocked", "assumptions": [], "open_questions": [], "conflicts_with_prior_decisions": []}
```

`partial` — часть каталогов недоступна (перечисли какие в open_questions);
`blocked` — недоступны все каталоги.
