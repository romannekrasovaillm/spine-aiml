# Cron-задача: дрейф-контроль AGENTS.md по флоту репозиториев

Прогони линтер AGENTS.md по реестру репозиториев и подготовь сводку для архитектора.

## Шаги

1. Выполни: `arch-be agents-md lint-all --registry ~/.arch-harness/repos.txt` (bash).
   Если `repos.txt` отсутствует — сообщи status blocked и подскажи создать реестр.
2. Для репозиториев со статусом `stale` предложи `arch-be agents-md refresh <repo>`.
3. Сводка: таблица «репозиторий → статус → действие»; в конце — JSON-статус.

## Формат отчёта

- Покрытие: сколько репо с AGENTS.md / всего в реестре.
- Дрейф: у каких источники новее файла.
- Проблемы error-уровня — отдельным списком.

Последняя строка отчёта — JSON: {"status": "complete|partial|blocked", "summary": "…"}.
